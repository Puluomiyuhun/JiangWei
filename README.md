## 本轮改了什么

修订49场、80处，正文净增599字符。重点第九至十三回，并回查前文政治、归兵、粮仓及承诺的回指。先说明交易收益和实际后果，把名目改成具体的人与行动；压缩重复心声及连续巧答，保留魏吴关系网和已有温情场景。第一回不改，未续写第十四回。

逐处对照见 [修改记录](project/本轮可读性修改记录.json)。新的 [文风准则](knowledge/规划与研究/当前文风准则-可读性与人物温度.md)、[原作与Claude对读](knowledge/规划与研究/原作与Claude对读-可读性复核20261016.md)、累计用户意见与完整交接已同步；上一轮后续节奏、反转评估也已收入知识区，明确标为未实施方案。陇西已有第八回来使，末回状态表的旧误记已改。

## 构建与校验

需要Python 3.10或以上版本，无第三方Python包依赖。在仓库根目录运行：

```sh
python -X utf8 project/mod_build/verify_revision.py
```

命令会编译完整十三回并执行静态校验，输出到 `project/mod_build/build/`。该目录被Git忽略；已核验的交付镜像在 [project/RS](project/RS/)。命令不会启动游戏，也不会复制到游戏目录。

仓库附有必要的Data人物表、Pmap格点数据、原作接入模板和E5/EEX解码工具，因此不依赖原作者电脑的盘符。默认只以音频文件名清单验证CD映射，**不包含音乐文件，也不据此认定音乐已经试听**。

如需核对本机游戏的真实人物表、地图元数据与音乐文件，可在PowerShell指定：

```powershell
$env:JIANGWEI_GAME_DIR='F:\曹操传反编译\测试mod\游戏'
python -X utf8 project/mod_build/verify_revision.py
```

`JIANGWEI_ORIGINAL_RS_DIR` 可另指定含原版 `R_00.EEX`、`R_33.EEX` 的模板目录；通常直接使用仓库模板即可。修改分回稿后须同步整本，构建器会拒绝两者不一致的版本。

## 使用与当前验证范围

- **本轮只提交，未覆盖游戏。** 当前R镜像已更新；游戏仍为上次《东吴政局关系明写修订》。看 [部署状态](project/部署状态.json)，[部署记录](project/部署记录.json)保留上次实际安装事实。
- 源稿与EEX对白逐框一致；5059个对白框，实际分页均在完整句末，每框最多三行。角色在场、斜角逐格移动、回目跳转、原作接入17块和末回919待续守护均通过。
- R00全部字节不变，其余十二个R重新编译；全部非对白指令与前版相同，Data和S未改，见 [技术保留核验](project/本轮非对白保留核验.json)。异路径构建与镜像的一致性见 [仓库复现核验](仓库复现核验.json)。
- 仓库最小输入支持重新编译，但不含完整游戏、美术和音乐。迁往其他底本须核对人物槽位、背景与音频资源；构建不会自动替换游戏Data。
- **未实机试玩**，未验证画面遮挡、动画或旧存档恢复。**S战斗仍为占位**，本仓库不是完整游戏发行包。

[来源清单](来源清单.json)记录初始导入时的原位置与源文件哈希（此后修改由Git追踪，不代表当前文件哈希）；[文件SHA256](SHA256SUMS.txt)记录仓库交付内容。历史文档中的本机路径、旧进度和“已经修好”的判断仅作历史，不是当前操作依据。未收录聊天数据库、账户配置、游戏程序、背景图片或音频文件。

原作与MOD素材保留各自来源；本次整理没有为它们另行授予开源许可。远期剧情规划含大量剧透，续写时按需阅读，不主动向玩家展开。
