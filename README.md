本仓库保存已写剧本、可部署R文件、构建与静态校验工具，以及Claude与后续协作积累的写作、人物、音乐、剧情规划和研究资料。**当前正本只有 `project/` 一份**。旧稿、旧审阅结论与原作不同分支均不能覆盖当前正文。

## 本轮改了什么

通读全部27个吴方人物出场场景，修改22场、37处，正文净增419个字符。主要替换原有含糊心声，说明具体事务上谁与谁合作、谁担心损失什么、为何改变立场。同步纠正陆凯与陆抗的族兄弟关系、虞汜的派遣来源和各营分报的授权来源。

第七回粮仓因果修订、全部非吴场景和第十三回末状态保持。没有续写第十四回。详细对照见[本轮修改记录](project/本轮修改记录.json)和[关系核对](project/本轮关系核对.md)。

## 构建与校验

需要Python 3.10或以上版本，无第三方Python包依赖。在仓库根目录运行：

```sh
python -X utf8 project/mod_build/verify_revision.py
```

命令会编译完整十三回并执行静态校验，输出到 `project/mod_build/build/`。该目录被Git忽略；已核验的交付镜像在 [project/RS](project/RS/)。命令不会启动游戏，也不会复制到游戏目录。

仓库附有必要的Data人物表、Pmap格点数据、原作接入模板和E5/EEX解码工具，因此不依赖原作者电脑的盘符。默认只以音频文件名清单验证CD映射，**不包含音乐文件，也不据此认定音乐已经试听**。

如需核对本机游戏的真实人物表、地图元数据与音乐文件，可在PowerShell指定：

```powershell
$env:JIANGWEI_GAME_DIR='F:\曹操传反编译\测试mod\游戏'
python -X utf8 project/mod_build/verify_revision.py
```

`JIANGWEI_ORIGINAL_RS_DIR` 可另指定含原版 `R_00.EEX`、`R_33.EEX` 的模板目录；通常直接使用仓库模板即可。修改分回稿后须同步整本，构建器会拒绝两者不一致的版本。

## 使用与当前验证范围

- 已部署版本对应 `R_00.EEX` 至 `R_12.EEX`。本轮只更新后十二个R；原第一回、Data、S未改。部署与备份记录见 [部署记录](project/部署记录.json)。
- 现有测试MOD沿用原人物表。迁往其他底本时，应核对人物槽位与背景资源；仓库Data是复现所用的输入，构建不会自动替换游戏Data。
- 全十三回源稿与EEX对白逐框一致；5042个对白框，实际分页均在完整句末。每框最多三行；角色在场、斜角逐格移动、回目跳转、原作接入17块和末回919待续守护均通过。
- 所有非对白EEX指令与前版完全一致。仓库可迁移构建生成的十三个R与本地已部署版逐字节一致，见[仓库复现核验](仓库复现核验.json)。
- **未实机试玩**，未验证画面遮挡、动画或旧存档恢复。**S战斗仍为占位**，本仓库不是完整游戏发行包。

[来源清单](来源清单.json)记录资料原位置与源文件哈希；[文件SHA256](SHA256SUMS.txt)记录仓库交付内容。历史文档中的本机路径、旧进度和“已经修好”的判断仅作历史，不是当前操作依据。未收录聊天数据库、账户配置、游戏程序、背景图片或音频文件。

原作与MOD素材保留各自来源；本次整理没有为它们另行授予开源许可。远期剧情规划含大量剧透，续写时按需阅读，不主动向玩家展开。
