## 构建与校验

Python 3.10或以上，无第三方包依赖。在仓库根目录运行：

```sh
python -X utf8 project/mod_build/verify_revision.py
```

命令编译全部十四回并静态校验，输出到被Git忽略的`project/mod_build/build/`。已核交付镜像在[project/RS](project/RS/)。命令不会启动游戏或部署。

仓库附Data人物表、Pmap格点、原作接入模板与E5/EEX工具，不依赖原电脑盘符或CherryStudio聊天库。默认以音频文件名清单检查CD映射，不含音频，也不表示已试听。源稿与整本不同步时构建会拒绝执行。

若需核对本机实际资源，可在PowerShell指定：

```powershell
$env:JIANGWEI_GAME_DIR='F:\曹操传反编译\测试mod\游戏'
python -X utf8 project/mod_build/verify_revision.py
```

`JIANGWEI_ORIGINAL_RS_DIR`可指定含原版R_00、R_33的模板目录；通常用仓库模板即可。构建不会自动替换游戏Data。
