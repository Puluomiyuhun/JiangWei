## 0. 项目定位

- **底本**：姜维传 6.5pl 加强版。历史线在 R_32「命运的决断」选择不派兵守阴平，R_33 演投降、事机败露、钟会之乱，姜维死于乱兵。
- **本线**：接 R_33「事机败露」，分歧只有一处，就是夏侯和多走了一步，问了钟会一句「丘建在跟您之前，是谁的左右？」。钟会醒悟，胡烈在城楼上喝退儿子，说出「没有坑」，钟会活过正月十八。目标是姜维借钟会之手复国，规划为六卷三十六回。
- **反例**：R_000「雨夜密谋」是 Claude 4.6 写的，网文腔，不要模仿：
  - 用英文省略号「......」和破折号「——」；
  - 「将军滴水不漏啊」这类句子；
  - 独白直接说出谋划，如「钟会想自立…这倒是个机会」（问题不在说出来，而在说得像网文）。
  - **但它有优点，要用原作的腔调吸收**：一扫就懂；不废话，每句都有含量；整体诙谐。不学它的标点和腔调，学它的「好读」。

## 1. 原作文笔（从 R 系列 25,496 句统计 + 精读得出）

### 1.1 基本数字（style.py 口径）

| 指标 | 原作 R20/27/31/33 | 当前新稿 |
|---|---|---|
| 台词平均长度 | 28.8 字 | 25.9 字 |
| 括号内心独白 | 13% | 7% |
| 问句 / 感叹 | 23% / 10% | 25% / 11% |
| 整行只有「………」 | 0% | 0% |
| 场尾连着两句以上内心独白 | 22% | 4% |
| 地图文字 / 旁白：场次 | 117 / 133 | 每回 8～11 条 |

- **体量**：原作 R_01～R_58 每个剧本的中位数约 10800 字、15～20 场。本稿每回目标是 9000～12000 字、14～18 场。
- **长短句**：短句（6 字以内，如「是…」「丞相…」「干。」）只放在情绪转折点。

### 1.2 政治斗争：写结构，不写阴谋

- **一句独白摆出派系利益**：挥泪斩马谡，台上走的是赏罚程序，杨仪的独白却是「我们荆州人这次必须要靠马谡的头度过危机」。
- **台面一套，台下各有心思**：仇国论朝会，郤正、陈祗、樊建、黄崇每人一句独白，合起来就是一张政治地图。
- **底层视角**：高平陵之变不写曹爽和司马懿，只写府门前两个小兵对峙。
- **对立双方都有理**：谯周的原文整段引用；杨戏羞辱姜维，姜维也认下「他说的一点也没错」。

### 1.3 括号独白的三种用法

1. **暴露动机**：台词之下的真实算盘。
2. **观察他人**：主角的屈辱，让旁人的眼睛去看（向充、来忠、宁随各一句）。
3. **反差**：嘴上一套，括号里另一套。比如钟会嘴上说「心中罪恶感」，独白是「我就像只没牙的老虎」。

### 1.4 低声量、高信息

- **称呼**：脱口一声「幼常」，揭开宁随就是马谡。
- **小动作**：赵云「咳咳咳」，为他的死埋线；司马昭「脸上的厚粉」，暗示病重。
- **问句**：「那十余万大军真正的目标是什么人？」不点名，杀意已到。
- **配角吐槽透气**：羊琇想「我是经学名家，又不是文法吏，真是倒楣」。

### 1.5 情感

- 基调是克制。姜维「悲伤时用关心别人来压抑自己」，主角不正面哭，由旁人替他看见。
- 牺牲戏的写法：先吵架，众人轮番阻拦，最后一个人认下；落点放在一个小小的私心上。杨兰：「至少在这一刻，我和那尹香可是平起平坐的。」
- 结局写的是赦免，而不是悲壮。前面每一句关键台词都要回收。
- 反派也有家庭温度，比如司马昭和王元姬。

### 1.6 节奏与结构

- **三国平行剪辑**：每个 R 约 8 个以上事件，蜀、魏、吴各线交错推进，而且**各条线有各自的输赢**。比如 R_27 同时写孙綝政变、曹髦之死、陈祗之死，三条线互不依赖。
- **多人议事大场面**：原作用来把逻辑摊开吵，比如「投降命令」16 人、2291 字。
- **推理一步一句，并且回应反对意见**：丘建劝钟会，是一级一级推下去的。
- **先交底再执行**：主角会把计划讲给读者听（姜维「密议」一人 811 字），悬念放在能不能成。
- **猜错再纠正**：用来传递信息。王韬猜邓艾打了败仗，杜预纠正「从成都来信，就表示已经攻下成都了」。
- **地图文字做桥**：交代幕后的因果、时间流逝和消息传递。

## 2. 写作守则（正式版，与旧稿〇节一致，必须遵守）

1. **删的是废话，不是字数。**
   - 普通回应可以保留，用来表示迟疑、服从、不愿继续或确实听懂；只删无作用的重复，不把所有接话改成警句。
   - 形势分析、权衡利弊、长段独白可以一段两三句，前提是每句都有新信息：谁、为什么、接下来会怎样。
   - 单个对话框不超过约 55 字，超了就拆成同一人连续说的两条。
2. **标点**：省略号只用「…」，沉默用「………」，不用破折号。整行只有「………」的台词尽量不用；要沉默，就换成追问、否认、动作。
3. **括号独白是人物此刻的念头**：可以揭示私欲、误判、顾虑与说不出口的话，也可以改变下一句如何回答。关键行动因果要清楚，但不把每一句台词再翻译一遍。
4. **对手不降智。** 每一次赢都要付代价，代价落在姜维身上。
5. **重要信息交给称呼、小动作、问句。** 旁白只交代年月和结果。
6. **前面说过的话，后面要回收。** 新伏笔记进长篇正本的「二、本稿新增伏笔」表：埋在哪里、在哪回收。
7. **人要有语调，不能人人都在念警句。**
   - 情绪写进句子形状里：急了会重复、打断、说半句（「要是他已经…要是他…」）；怒了用短句、反问、感叹号；慌了结巴；嘴硬的人用「哼」「你自己想去」。
   - 克制的人也要有裂缝，比如「分得清，不等于不难受」。
   - 对仗工整的「金句」一场最多一句，留给真正的收尾。
8. **话里带料**（原作的核心笔法）：对话不只就事论事，要顺手捎出局势和背景。
   - **料的种类**：
     - 地理：某地通哪里、为什么要紧；
     - 人脉：父子、翁婿、门生、旧部；
     - 数字：兵、粮、户口、年份；
     - 旧事典故：吴汉屠成都、于禁羞死、傅肜骂「吴狗」；
     - 职官封爵；
     - 闲笔逸事：邓艾口吃「凤兮凤兮」、邓芝射猴。
   - **重大死亡或事件之后**，用 [地图文字] 写史料注脚，可引《三国志》和裴注。**最后一句落回本线的不同**：「而在这一年的正月，……」。
   - 料要由**知道这件事的人**，在**会提起它的时候**说出来，不能变成讲课。
   - **料不能冲淡情绪**。最好让料变成吵架的武器（拿对方的旧账堵嘴）、心里的旧伤、自嘲或挖苦。说料的人这一刻一定有所求，或者有所痛。
   - 连续三句平铺的背景，就用反问、打断或旁人的反应截开。料讲完，要落到一句带情绪的话上。

**好例子**（料当武器用，读起来不像讲课）：
```
【廖化】傅佥的爹傅肜，当年在夷陵替先帝断后。吴兵叫他投降，他骂了一句"吴狗！何有汉将军降者！"，就死在火里。
【廖化】父子两代，一个比一个死得干净！你倒好，开了门，换了身衣裳，又活着回来了！
【蒋舒】末、末将开了门，关里三千人都活了下来啊…傅佥不开，他自己死也就罢了，还要拉着三千人一起死…
【蒋舒】再、再说了…廖将军当年陷在吴国，不也是诈死逃回来的嘛。那时候…也没听谁骂廖将军不死节啊…
【廖化】你说什么？！
【蒋舒】没、没什么…末将多嘴。
【廖化】（傅佥，叔父老了。七十多岁的人，连个降将都骂不过。）
```
蒋舒的反驳有分量，但用的是降将的嘴：结巴、带「啊」「嘛」、说完就缩，不像英雄怼人。

## 2.5 明说五条（用户批准，可读性优先，压过一切「含蓄」）

用户反馈：比起原作，我们的稿子「藏得太过」，不能扫一眼就懂，显得神叨叨。原作的含蓄在**动作**上，不在**意思**上。

1. **关键行动要看懂。** 听众需要知道谁要做什么、为什么能或不能做；私人情绪、试探与误判可以保留余味。不要要求每句拐弯话在1～2句内由心理或旁人解码，更不要安排别人提问，方便角色解释自己的全部算盘。
   - 坏：卫瓘「去得早还是去得晚，就看他的马快还是田续的马快」。
   - 好：卫瓘「（糟了，姜维要去绵竹见邓艾。邓艾活着开口，我夜里拿他那件事就说不清了。得让田续赶在他前头。）」
2. **称呼默认用官职和姓名，字号酌情保留。** 默认：姜维称钟会「司徒」，旁人称卫瓘「监军」，胡烈叫「胡将军」，杜预叫「杜长史」。
   - 字号用在亲近、私下或带讥讽的口吻里，而且全名要先出现过（说话人标签或前一两句里）。读者一眼能对上是谁，就可以用。
   - 已保留的字号：钟会叫「伯约」、叫胡烈「玄武」、讥卫瓘「伯玉」；卫瓘自称「伯玉」；司马昭叫贾充「公闾」、叫杜预「元凯」；胡烈叫儿子「世元」；钟毓叫「士季」；夏侯霸叫「义权」「叔子」；谯周叫门生「承祚」。
3. **保留路标句**：「什么？！」「糟了…」「果然…」「原来…」。读者靠这些知道哪一句是转折。
4. **让观众及时知道场景在发生什么**，但不强制前两句点题。伤者归来、旧友重逢等场景，可以先顾眼前的人，再进入公事。
5. **警句每回最多两三句。** 旧事直接说名字（「江由那一回邓太尉要斩你」），不写「那件事」「那一夜的事」。

## 2.6 铿锵是少数人的专利；独白要带情绪（用户意见第 12 条）

1. **「A是真的，B是真的。C从来没说过」这种铿锵句，只给天生硬气的人。** 罗宪、柳隐、廖化、张翼、邓艾（倔）、庞会（冷）、夏侯和（冷）可以这么说话。
   - 圆滑的、懦弱的、降将、小人：同样的意思，换成他们的嘴。用「哎哟」「嘿嘿」「…嘛」「是、是」，结巴，说半句就缩回去，或者先讨好再刺一下。
   - 他们不必弱智，话里照样有刺；只是**刺藏在姿态底下**，不是正面硬顶。真正的狠话放进独白里（句安：「哼，降将借来的米，胡将军待会儿嘴里嚼的不也是这个？骂吧，骂完了，饭还得吃。」）。
   - 例：丘建原来是「将军们关着是真的，檄文是真的。坑，小人从头到尾没说过有。」，改成「哎哟，少将军这可冤枉小人了。将军们关着，是真的吧？檄文，也是真的吧？坑嘛…小人可从来没说有，是少将军自己问的。」
2. **独白是人物自己在心里喊，不是旁白替他总结。** 要有感叹、叹气、骂、半截话，「哎！」「啊！」「这傻小子！」。
   - 坏（像旁白）：胡烈「我喊一声有，就是亲手把他推到刀底下。」
   - 好：胡烈「（可世元这傻小子要是今夜攻城，赢了是擅兴兵马，输了就是死在城下啊！）」「（我只要喊一声有，就是亲手给我儿送葬…哎！）」
   - 坏：田续「监军这话听着像是替我想好了退路，可退路上站着的只有我一个人。」好：「好嘛，杀太尉的是我，护驾有功的是他。这条退路，怎么越听越像我一个人的断头路？」
   - 自检：把独白里的人名换成「他」，读起来像小说叙述的，就要改。

**象征梗只用一次**：「挖坑」「饿了三天」这类象征说法，只在开头当一次导火索，城楼上「没有坑」一句收住。人做决定要有**现实动机**，正常人不会看有没有坑来判断会不会被杀。本线魏兵的真动机：将军被关、钟会发檄文讨伐相国、自己是士家，家小在中原士籍上，跟着钟会就是反贼的家属；相国大军已到长安。

`mod_build/read.py`（在工作区根运行）统计可读性：用字比例、官称比例、独白含路标、代指旧事。明说修订后：用字 12%→5%（原作 3%），独白含路标 9%→14%（原作 25%）。

## 2.7 对白反差与心理活动（2026-10-16用户补充）

写后续或复修对白前，读[本轮原作复读与校准](references/dialogue-contrast-20261016.md)。最新对白稿为`C:/Users/puluomi002/Documents/Codex/2026-10-15/kan/outputs/前十回对白反差修订/`，承接音乐版；下文旧稿统计只是历史快照，不设字数或心理比例配额。

- 用户不喜欢“一人豪放发问，另一人准确接住、讲道理或翻成一句巧话”反复出现。重伤回来的“四个人抬／添了人手”就是反例。允许普通接话、未接全话、转移话题；幽默应服务人物当时要掩饰或争取的事。
- 心理活动进入交谈中间，影响答应、反驳和下一句话；不要总在场尾总结，不用括号重复解说已明白的机锋。也不机械禁止场尾心理。
- 心口可以不一：护短而嘴上认错，想出城却劝人等待，知道自己理亏仍先撑住，心里惦记旧怨而表面照常办事。反差不必都出于阴谋。
- 心理是主观念头，能猜错、自我宽慰、不愿承认；不要全员准确分析自己的私心、在每场结束前完成道德反省。
- 不把科普写成轮流授课，不把聪明写成每句都回得漂亮。既有清楚而必要的推理、好用的家常和少数机锋仍可保留。
- 本轮音乐、背景、进退和斜角调度沿用BGM版。修对白时继续核对出声／内心与实际在场关系，不为加心理提前让未登场者发言。

## 3. 六条修改方向（用户批准的「去背台词感」方案）

问题诊断：逻辑跳跃、像在背台词、视角只盯着成都。逐条对策如下。

1. **补必要的推理与条件。** 关键转折须能看懂决定如何形成；可以通过报告、争执、心理或行动呈现，不规定至少一问一答，不让下属反复替作者出题。
   - 反例：胡烈从「他们是自己来的」直接跳到「没有坑」。
   - 正例：钟会先算账「攻下来，乱兵杀了我也杀了你；攻不下来他死在城下；相国一到，擅兴兵马头一个斩谁？」，胡烈独白「檄文我没签，相国查起来我清清白白。可世元今夜攻城，赢了是擅兴兵马，输了是送死」，然后才说「没有坑」。

## 6. 剧本语法（md 稿 → 构建器）

每回写在 `## 卷X　名` → `### 第N回　题`（**全角空格**）下的 ``` 代码块里，一行一条：

```
[地图文字] 文本 | a | b | c        地图文字（0x2c），一组最后一条一般用 | 1 | 1 | 1；超过约 37 字会在标点处自动拆开
[事件名] 名                         开新场（0x18）
[音乐] N                            开场CD（0x24），紧跟[事件名]；台词间可再写以在该处换曲，选曲见§6.5
[地图音乐] N                        紧随的一组地图文字的CD；当前每组均显式指定
[场所] 成都 北门城楼                 换背景（0x17）；场内换地点就再写一条，会重新布景
[旁白] 文本                         无说话人的对话框
[登场] 甲、乙                       从该背景的门口（DOOR 表）沿一条斜角轴出现（0x30），走到站位（0x32）
[退场] 甲                           沿原路走回门口（0x32），消失（0x31），重绘（0x1e）
【角色】台词
【角色】（内心独白，用全角括号）
```

**构建器语义与断言**（违反任何一条，构建直接失败）：
- **开场在场的人** = 本段里在自己的 [登场] 之前就开口的说话人。**凡是后来才到的，必须先写 [登场]**；中途离开的，写 [退场]。站位不讲究也行，但出现、移动、消失的逻辑必须对。
- 同屏不超过 **8 人**；同一人不能重复登场；不在场不能退场；**说话人必须在场**。
- 每段 [场所] 会重置场上人员；同一场换地点，要重新登场。
- 对话框按约 19 全角字宽自动换行，每框最多 3 行，更长的台词自动拆成同一人的几个框。手写时一条控制在约 55 字以内。
- 说话人名必须能在 Data.e5 查到，否则没有头像和名字。通用龙套已占用 866～873 号槽：主簿、参军、老兵、新兵、魏兵、蜀兵、魏将、蜀降卒。原作已有的「士兵02」「武官」等可以直接用。新龙套要在 `GENERIC` 里加。
- **场所关键字必须命中 `BG` 表**（子串匹配，按顺序取第一个），否则会报 KeyError。新地点在 `BG` 里补背景号，音乐按本场显式指定，不再给背景配置默认曲；背景号参考原作同类地点。
- 地图文字后需要旁白时，显式新开[事件名]、[音乐]、[场所]，避免产生没有配乐定义的匿名场。

**站位（R 场景是斜角坐标，用户提醒）**：投影 `sx=(x-y)*8`、`sy=(x+y)*4-z*8`（scenerender.c SceneRender_Project32）。同 y 变 x 是屏幕右下/左上斜线，同 x 变 y 是左下/右上斜线；朝向 f1=+x、f3=−x、f2=+y、f0=−y。
- `LAYOUT[背景号]`：照原作同背景的阵型取 8 个槽位，前两个面对面，供对话双方；`layout()` 在槽位附近螺旋找不被 Pmap 阻挡的格子，人与人至少隔 4 格。
- `DOOR[背景号]`：后到者的出现点，`('x',X)` 同 y 从 x=X 走进，`('y',Y)` 同 x 从 y=Y 走进，`('pt',x,y)` 固定门口。新背景要同时补 LAYOUT 和 DOOR，否则用 DEFAULT。
- 不要再用「上方 N 格」这种直角坐标思路，斜角坐标里 y−14 是斜着飘下来的。

## 8. 写一回的检查清单

- [ ] 一回只写一段连续的时间，镜头在 4～5 条线之间切，含至少两条非成都、自有输赢的内斗线（东吴、魏廷/洛阳、长安、南中）。
- [ ] 节奏：一件事不超过 3 场，过程用地图文字跳；主线场次约占一半；一般场 8～15 句。
- [ ] 场次配比：主线 7～9、别处内斗 4～6、小人物 2、收束 1；16～20 场，9000～12000 字；有一场多人议事。
- [ ] 每一场都推动一件事、改变一个人的想法，或者是立人物的小品（每回 1～2 场，见意见 15）；只为铺背景、交代过程的场次删掉。
- [ ] 关键转折前有推理链，决定者自己的那一步说出来了；至少一处猜错再纠正。
- [ ] 无纯接话、无车轱辘话，同一意思不在相邻场次重复；无破折号、无英文省略号。
- [ ] 每个说话的人都有自己的语调，一场最多一句对仗金句。
- [ ] 明说：拐弯的话 1～2 句内被解码；称呼用官职姓名；场首两句点题；旧事说名字；象征梗不反复。
- [ ] 铿锵句只给硬气的人；圆滑、懦弱的人用自己的嘴说话；独白有感叹、叹气、半截话，不像旁白。
- [ ] 料有出处、有动机、有情绪落点；大事件后有地图文字注脚，结尾写「而在这一年……」。
- [ ] 场尾独白约三成，而且是算计或钩子。
- [ ] 胜利有代价，落在姜维身上；对手没有降智。
- [ ] 新伏笔记进正本伏笔表，回收了前面的伏笔。
- [ ] 后到的人写了 [登场]，离开的人写了 [退场]；同屏不超过 8 人；新地点补了 BG/MUSIC；新龙套补了 GENERIC。
