# 本轮原作、Claude与现稿对读

2026-10-16。阅读记录用于说明改稿依据，不把审阅者的“清楚”当作用户无需再反馈的结论。

本轮完整连读第九至十三回，并回看第一回全部脱险链，连读第六回，复查第二至八回的魏吴议政、粮仓及其回指、归兵与家属安置等场景。修改范围由具体阅读障碍决定；没有为凑全回改动而重写第一回。

## 读过的参照与学到的做法

| 参照 | 本轮阅读重点 | 可采用的做法 |
| --- | --- | --- |
| Claude阶段长篇《旧主》 | 谁曾是谁的亲信，为什么突然能改变局面 | 先给能决定行动的一条关系，再给报告与决定；不用人物志开场 |
| 同稿《棺木》 | 刘禅既恨京观，又记得邓艾烧自己的棺木 | 事件很清楚，感情可以不清楚；人物不是先选好道理再开口 |
| 同稿《兄弟》 | 同一句劝告被兄弟理解、使用，母亲的评价伤到炎 | 政治知识通过家人的比较产生情绪后果，不是插一段教学 |
| 同稿《一碗饭》《药方》 | 胡家士卒的处境与借探病往来的信息 | 利益落实到饭、去留、能否见人；仍须警惕连续巧答，不逐句仿写 |
| 原作R_19《责任归属》《立誓》 | 费祎与将领在问责中的立场 | 救人、保将、承担过错可以同场交叠，不必人人当场和解 |
| 原作R_26《虎将虎子》《战后的安排》 | 家世、怕死、忠义与监控 | 口头相同表态有不同私心；对话不用先讲完整谱系 |
| 原作R_26《逆转的大计》《含恨退兵》《仇国论》 | 军事计划、朝廷反对、地方利益与人物反应 | 先说明要做什么与具体困难，再让各人带不同感情参加；反对者并非无故坏事 |
| 原作R_27《司马昭的真意》《恶梦》 | 拆分荆州权力的实质、废立中的私人记忆 | 先让观众理解权力如何变化，心声揭出更深目的；受害与施害经历会留下情绪 |
| 原作R_28《钟会的野心》《陆抗的见解》《邓艾抗命》 | 公开部署与争功、用将、抗命的动机 | 谋划首先是一件可执行的事，野心嵌在部署里；不以语句含混充当深度 |

参照在仓库 `references/姜维传原文` 与 `archive/Claude阶段原稿`，均为本地文本。以上是本轮重点阅读范围，不表示重新考证原作全部史实。原作有不同分支；文风借鉴不等于把其中事件都搬成当前线的既成事实。

## 现稿的主要问题及实际处理

一是抽象名目替代了利益。第七回“军户、军籍、核田”连用，让王含为什么不愿北上变得难懂。现在先写士卒想家人留在汉中、拿回田过日子，句安说明已有别人被安置在田上，钟会只准先给粮、田归谁另查。冲突没有缩小，读者却可以立即判断各方在争什么。

二是条件有了，交易缘由没先说。第十二回吴国通粮，原文上来就怕南中腾出兵援吕兴，观众容易问：既然全是坏处，吴国为何答应？新稿先说明姜维牵制魏军是吴国所得，再分别讲首批和后批、陆抗与罗宪各能控制哪一段。

三是“半真半假”没有说是哪一半。樊建承认把援兵数送给杜预，是已知事实；匿名抄件如何加上截粮判断、由谁送来，仍未查明。现在由钟会当面分清，不重新卖已经揭开的谜底。

四是反问与漂亮收尾过多。“由我先做”“多留一处可说”“今日不要先私分恩典”都改为当事人答应做什么。来忠说自己带书进关；丁奉说不要预许官兵、宫卫仍由自己守；姜维直说自己来劝刘禅答应，也得听完拒绝的理由。

五是重复解释挤掉了人的反应。郑冲与王祥已分别讲过底线，不再请荀顗第三遍念分案原则。陶璜不再总结所有朝臣的站队，改想父亲旧人究竟还认不认自己。陆凯承认帮韦昭也有替陆抗结交的私心，而非一口气把整个文臣集团分类完。

另纠正两处数目／去向回指：第九回姜维当场讨的是钟会先前夸口的八千，不能心声忽然又变五千；第三回邓艾仍赴长安、旧部回陇西，不能写邓艾活着回陇西。第十三回陇西无“新信”，不等于第八回从未来使。

## 本轮保留的东西

没有删掉魏吴多方关系，没有加新人物或新场，没有揭晓未定的卧底；第一回胡渊停兵、放将验人、两军互制的逻辑保持。第十一回杨兰与果看伤、姜维陪走，第十二回刘禅害怕与关家相见，第十三回树下和果儿问家事，这些已有温度的段落保留。

本轮不是把所有人物都改成直话直说，而是先让观众知道他们为何要绕着说。文意质量仍需玩家阅读反馈，编译通过只证明技术格式与衔接，不证明每场情绪已达到原作水平。
