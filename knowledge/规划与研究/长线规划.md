## 一、总体设计

### 1. 一句话主题
姜维要的是「汉」，钟会要的是「天下」，魏兵要的是「回家」，益州人要的是「别再打了」。四种愿望捆在一辆车上，谁也离不开谁，又谁都在拽缰绳。每赢一次，就有一个人被车轮碾下去，最后剩在车上的人，没有一个是当初想要的样子。

### 2. 三条主矛盾（贯穿全书）
| 层 | 矛盾 | 走向 |
|---|---|---|
| 势力外 | 汉、钟 对 司马氏 | 卷一至卷三上升，卷三「崩」跌到谷底，司马昭死后反弹，卷五换成 晋（司马炎、杜预、羊祜）再压上来 |
| 同盟内 | 姜维 对 钟会 | 互相利用 → 互相需要（卷三钟会哭）→ 鸿沟（卷四）→ 钟会死于自己人（回28）。姜维从头到尾没有亲手动钟会，这是他的底线，也是他付出的代价 |
| 自家内 | 复国派 对 益州人；姜维旧部 对 降将、新附 | 谯周、范长生、益州大姓要的是「不打」；廖化、张翼要的是「旧主复位」；姜维要的是「汉还在」，这三者到卷六才在刘璿身上勉强重叠 |

### 4. 节奏曲线（高低交替，大约四到五个 R 一次大爆发）

```
卷一  ▁▃▅▇  北门/绵竹/关府，紧张升起；关府之后斩庞会是第一个冷峻的小高潮
卷二  ▅▃▆▃█  乐城胜 → 傥骆道被抄后路 → 剑阁雪（姜维亲手处置旧同僚）→ 永安（罗宪的一个月）【爆发1】
卷三  ▃▅▆█▁▂▅▆█  五丈原、陈仓 → 渭南崩【爆发2：张翼】→ 谷底收尸 → 陇右归、冀城见母 → 夏侯霸死城门【爆发3】
卷四  ▅▃▄▆▃▆█  厚粉之后的松一口气 → 鸿沟 → 河西 → 让位、劫驾之夜（刘禅睡着了，静的爆发）→ 江陵 → 宁随替死【爆发4，全书最重】→ 钟会死
卷五  ▂▄▆▇▅  寄人篱下，低开 → 潼关压境 → 胡烈的选择（士家回家）→ 羊叔子
卷六  ▅▆█▃▁  范长生讨债，最难的抉择 → 白水【爆发5：杨兰】→ 还都 → 冀城，安静收尾
```

爆发点规则：
- 全书大爆发只有五次（回10、15、19、27、34），中间用「小爆发」托着：回5 斩庞会、回16 钟会哭、回24 刘禅睡着、回31 胡烈。
- 爆发前两个 R 必须有「笑」：斗嘴、吐槽、小人物闲笔。爆发后一个 R 低开，用小人物视角收拾残局（收尸、缝衣、点名少了谁）。
- 爆发的写法守 SKILL §1.5：先吵，众人拦，最后一个人认下；落点在一个小私心上；主角不正面哭，由旁人替他看见。爆发场里金句只许一句。
- 爆发场之后紧跟一条地图文字史料注脚，落「而在这一年……」。

## 二、分卷细案

### 卷一　成都七日（回1～5，三关，已写）
- 定稿状态：见 SKILL §7 长篇进度。
- 卷一留给后面的钩子：丘建一炷香、胡烈「名字写在你上面」、十九个名字、庞营两千人屯宫门（回28 用）、关彝请随前锋、阎宇的「等」、范长生的债、宁随的身份、羊祜府里的夏侯霸。

### 卷二　出汉中（回6～12）
**卷意**：赢了也是输。每一次胜利都抽掉钟会军一块骨头。

- **回6 士家**：粮车上的布告进城。魏兵吃饱了就走，每夜少几十人。
  - 内：钟会要斩逃兵立法，胡烈拦（他的兵逃得最多）；姜维出主意，不斩，发「归籍文书」让想回家的人走，钟会骂他「替相国点兵」。
  - 情：老兵、新兵线收束，新兵拿着那五匹绢走了，老兵留下。「我在中原也没有家了。」
  - 姜维私下：放走的人越多，留下的越是钟会的死党，这正是姜维要的；独白交底。
- **回7 乐城**（关4 战斗）：王含阵前唤回四千旧部，胜。
  - 反转：同一夜贾充走傥骆道，句安刚被钟会封为汉中太守就献出了南郑外仓。句安的降将本色在这里兑现（不是坏，是看风向）。
  - 关彝初阵，砍倒一员魏将后吐了。姜维没说话，杨兰替他擦了刀。
- **回8 白起**：邓艾在长安死。裴秀主杀，杜预沉默，卫瓘不在场却最高兴。
  - 姜维听到消息那一场：没有台词，只有一条地图文字和他把邓艾当年在段谷留下的一支箭折了。（小静点，不算爆发）
  - 陇西军派人来问姜维，不问钟会。钟会知道了。→ 回14
- **回9 剑阁雪**（关5 战斗）：阎宇献关。姜维回师一日。
  - 内（蜀）：阎宇是黄皓旧党，他开价「益州刺史」，杜预回的那个「等」原来是「等你先动手，我好不认」。阎宇被晋人卖了。
  - 姜维亲手斩阎宇？不。让柳隐斩，姜维在旁边看着。来忠问「大将军为何不亲自动手」，姜维：「他是我的同僚，柳将军跟他没有交情。」→ 姜维的底线：不亲手杀自家人（对照回28 钟会，回27 宁随）。
  - 向充（向宠之弟）开门迎姜维，冻掉两根手指。伏：回35 向充在还都大典上执旗，手套是缝过的。
- **回10 永安**（关6 战斗）【爆发1：罗宪的一个月】
  - 外：陆抗三万溯江，永安守到第三十一天。
  - 内（钟会军）：钟会要弃永安（「蜀东一座孤城，换陆抗一纸和约」），姜维分兵五千，钟会只给三千还是降兵。廖化自请带兵：「老夫在吴国待过，认得他们的旗。」
  - 爆发：援军到的时候，罗宪站在城头，旁边是杨宗的尸体。杨宗从成都回来，翻山时摔断了腿，爬了三天把「一个月」带进城，城里人才守下去。罗宪对姜维只说一句：「大将军说一个月，就是一个月。我数着日子。」
  - 落点（小私心）：罗宪递给姜维一张纸，上面是三十道划痕，最后一道是杨宗划的，歪了。
  - 收：陆抗退兵前派人送来一坛酒，附言「永安是本钱，留着以后谈」。→ 回26
- **回11 南中**：霍弋要北上，爨氏、孟氏开价（免租十年）。吕兴叛吴的消息传来。
  - 花鬘想去北边见姜维（她和关索都是诸葛亮南征的旧缘），关索想去交趾抢功。夫妻之争是南中线的人情。
  - 霍弋的决定：派关索、花鬘带三千南中兵北上，自己留下守。→ 回13 起关索、花鬘入队。
- **回12 长安的女人**：曹绫自己说破遗诏是假的，当着司马昭和王元姬。
  - 内（司马家）：王元姬要杀，司马昭不杀，理由是「她说了真话，杀她，天下人就会以为遗诏是真的」。
  - 曹绫想起许仪（回1 伏）。夏侯霸在羊祜府里得知此事，决定去长安。→ 回19

**卷二收束**：钟会军从十几万掉到七万，姜维手里的蜀军反而从一万多涨到两万（剑门、永安、南中）。钟会第一次说「伯约，你的兵越来越多了」。

### 卷三　五丈原（回13～20）
**卷意**：回到丞相死的地方，再死一次。然后活过来。

- **回13 旧营**（关7 战斗：斜谷口，与魏将牵制部队的遭遇战）
  - 宁随在五丈原独自走到一处营址，蹲下摸了很久。杨兰看见，以为他在找东西。诸葛果看见，脸色变了（她认得父亲的营法，也认出了这个人是谁，但不说）。→ 回27
  - 内（姜维一系）：军议，廖化骂宁随「纸上谈兵」，宁随回一句「廖将军说得对，纸上的兵，我谈过一回，死了很多人」。全场只有诸葛果和姜维听懂。
  - 吴：孙休崩，孙皓立（地图文字＋张布一场）。张布押错了宝。
- **回14 陈仓**（关8 战斗）
  - 钟会要先拔陈仓，姜维说起郝昭。钟会不听，强攻三日不下。是姜维的一条小计破的城，功劳记在钟会头上，姜维不争。钟会更不安：「他不争，是因为他要的东西比这个大。」
  - 陇西：王颀、牵弘各遣使，王颀的使者直接到姜维帐中。钟会扣了使者。
- **回15 崩**（关9 战斗：渭南撤退战）【爆发2：张翼】
  - 前因：卫瓘早把十九将名单抄给了长安（回5「十九个名字」）。司马昭阵前宣赦，按名字一个一个念，念到谁，谁的营就乱。
  - 胡烈的名字是第一个念的，他没走。他的兵走了一半。
  - 卫瓘在乱中脱身归晋。
  - 爆发：张翼请断后。撤退之前，他和姜维为了九伐中原的旧账吵了最后一架（张翼一辈子反对北伐）。
    - 张翼：「我反对了你九次，这一回不反对了。你走，我在这。」
    - 落点：张翼让儿子张微跟着姜维走，「我反对你，他不反对。」
  - 注脚：史载张翼死于成都乱兵（264 正月）。「而在这一年的五月，他死在渭水南岸，身后是他反对了半辈子的北伐。」
- **回16 收尸**（低开，小人物视角）
  - 羊琇放回蜀军伤兵（违令），说是辛宪英的锦囊里写的。其实锦囊里没写，是他自己。
  - 胡烈替张翼收尸，因为张翼当年在临洮放过胡烈的一个族弟（新料，只在这里用一次）。
  - 钟会第一次在姜维面前哭：「七万，剩三万。伯约，我是不是真的不会打仗？」姜维没有安慰他，替他算了账：剩三万，可三万都是不想回家的人了。
- **回17 陇右**（关10 战斗：陇右追兵）
  - 王颀、牵弘举陇西来归，师纂不肯，带兵追杀，被邓忠拦下：「我爹放过的人，你不能杀。」→ 邓忠继承邓艾的倔。
  - 内（陇西）：王颀要给邓艾翻案，牵弘要活路，两人在姜维帐前吵，姜维拍板：翻案的檄文用钟会的名义发。钟会第一次看清，姜维在用他的名字收人心。
- **回18 冀城**：姜维回天水见母，祭尹香。
  - 情感线核心场之一：母亲问杨兰「你是谁家的姑娘」，杨兰说不出口，诸葛果替她说「是大将军的人」，母亲看了两个人很久，什么都没说，给了杨兰一副手镯（尹香留下的）。→ 回34
  - 杨兰当夜把手镯还给姜维：「这是尹香姐姐的，我戴不上。」姜维收着。
- **回19 天子**（关11 战斗：长安城门护送）【爆发3：夏侯霸】
  - 夏侯霸、曹绫送曹奂出长安。夏侯和在城外接应（兄弟相见是三十年后，夏侯霸当年降汉，夏侯和留魏）。
  - 内（魏室）：曹奂不想走，「朕走了，长安的宗室怎么办」；曹绫：「陛下留下，长安的宗室全都要死。」
  - 爆发：夏侯霸死于城门，替曹奂挡箭。临死对夏侯和说：「义权，叔子家里还有我一个孙子，你别去接他，让他姓羊吧。」
  - 落点：夏侯和一辈子冷，这里只说了一句：「哥，你降了汉，到底还是死在魏的门口。」
  - 注脚：夏侯霸史载卒于蜀（约 259）。本线另立。
- **回20 厚粉**：司马昭病死军中，晋军东撤。
  - 王元姬为他上最后一次粉。司马昭临终叫的是司马攸的名字，贾充改成司马炎（伏：回25）。
  - 钟会入长安。他站在未央宫旧址上，问姜维「张良当年也站在这里吧？」姜维：「张良站在这里的时候，刘邦已经杀了韩信。」（警句，本回唯一一句）

### 卷四　两个天子（回21～28）
**卷意**：仗打完了，人开始互相算账。这一卷外患最轻，内斗最重。

- **回21 鸿沟**：钟会划界「还蜀地」，汉中、陇右不在其内。姜维一系炸锅。
  - 内：廖化要当场翻脸，宁随拦：「今天翻脸，明天魏兵就有理由打回成都。」姜维接受了钟会的划界，所有人都不懂。只有宁随懂，姜维在等钟会犯错。
- **回22 凉州**（关12 战斗：河西）
  - 秃发鲜卑南下。姜维用羌人旧交（他少年时在天水与羌人的交情）换来河西的路，钟会起疑：「他在给自己留一条退路，还是一条进路？」
  - 关索、花鬘在河西立功，南中兵第一次在北方打仗，水土不服死了很多。花鬘哭，关索骂她，晚上偷偷替她点名。
- **回23 仇国**：成都议复国，谯周率益州人反对（回2「受一次辱，够了」回收：谯周当众说「我受过一次降的辱，你们不能再让我受一次复国失败的辱」）。
  - 多人议事大场面。益州派、荆州旧人、东州旧人、姜维旧部四方吵。
- **回24 让**（关13 战斗：劫驾之夜）
  - 刘禅不肯复位，立刘璿，自己背降名。那一夜，黄皓旧党与益州大姓的几家，勾结卫瓘从长安派来的人，要劫刘禅送洛阳（重演史实里刘禅东迁）。
  - 战斗：姜维带人在成都护驾，敌是黄皓旧党私兵。
  - 战后小爆发（静）：刘禅睡着了（回1「朕想睡一个整觉」回收）。张皇后的金钗（回2）给了刘璿的太子妃。廖化跪在刘禅门外到天亮，旧主不肯复位，他这一辈子跟的是先帝、丞相、陛下，现在要跟一个孩子。
- **回25 洛阳**：司马炎受禅称帝。司马攸被迫叩头。
  - 夏侯霸遗孤在羊祜府中，羊祜对着孩子说「你祖父死在长安城门」。羊祜开始对西边有了私人的理由。→ 回32
  - 钟毓一家（回1「必不以及宗」）：司马炎赦钟家，钟毓却病死了。钟会得知，没有哭。
- **回26 江陵**（关14 战斗：巫峡伏击）
  - 陆抗遣使，愿以永安换盟。但孙皓另派了一路使者，要的是「割汉中给吴」，两路使者在巫峡撞上，孙皓的人伏击陆抗的使者。姜维的人护使者出峡。
  - 内（吴）：陆抗与孙皓的裂缝在本线第一次见光。
  - 姜维要的不是永安，是荆州的一句「承认」，陆抗给了（私人名义），「汉」第一次在外交上有了名字。
- **回27 影子**【爆发4：宁随（马谡）】
  - 钟会要姜维入长安为魏大将军，名为重用，实为夺兵。同时长安查出回9 剑阁斩阎宇、回17 用钟会名义发檄文的事，钟会军中魏将要有人为此负责。
  - 罪名需要一个「替姜维出谋划策的人」。宁随自承：「出主意的是我。」
  - 先吵：姜维不准，廖化不准（廖化骂了宁随一辈子，这时候第一个站出来拦）、诸葛果跪下求、杨兰骂「你这个书呆子」。宁随一个一个说服。
  - 爆发：临刑前，姜维脱口叫了一声「幼常」。宁随笑：「伯约，丞相当年斩我，是为了军法。你今天不斩我，是为了情分。可我这颗头，是留给今天的。」（回1 起的「那颗头」伏笔收尾）
  - 落点（私心）：他对诸葛果说「你父亲哭着斩我，我这辈子只想跟他说一句：街亭是我的错。现在我说给你听了。」
  - 注脚：《三国志·马良传》附马谡传，裴注引《襄阳记》。「而在这一年的冬天，有一个叫宁随的人，替另一个人死了第二次。」
- **回28 今之张良**（关15 战斗：长安宫变）
  - 钟会欲废曹奂自立，曹绫不从。钟会要杀曹绫。
  - 丘建回来了（回1「一炷香」回收），带着回5 屯在宫门外的庞营两千人。庞营老兵恨钟会斩庞会，丘建只需要开一次门。
  - 战斗：宫变，姜维杀入宫中，目标是救曹绫和曹奂，不是救钟会也不是杀钟会。
  - 钟会死于旧部。姜维赶到时，钟会还有一口气：「伯约，你是故意来晚的吗？」姜维：「是。」（姜维这一生最狠的一个字，代价是他从此背着这个字）
  - 丘建：「这一回小人也只做得了一炷香的主。司马家那一半，还了。」随后自尽，或者跑了？→ 跑了，回33 出现在范长生身边（伏笔，丘建一辈子还债）。

### 卷五　关中（回29～32）
**卷意**：寄人篱下的是魏，撑着屋顶的是汉。外压最重的一卷。

- **回29 寄人篱下**：长安魏室反过来求汉。曹绫与姜维以渭水为约。
  - 关彝遇到庞会的遗腹子（回5「四十五年以后，又一个姓庞的孩子」），孩子母亲来要关家偿命。关彝收养他。
  - 内（魏室）：夏侯和主张借汉兵，宗室们骂他「夏侯家的人，降汉降上瘾了」。
- **回30 潼关**（关16 战斗）：晋军西进，杜预为前锋。旧日镇西长史站在关下。
  - 卫瓘在杜预军中，二人互相看不起。杜预：「伯玉兄，你在成都装了三个月病，现在病好了？」
- **回31 胡玄武**（关17 战斗：潼关之二）【小爆发：士家回家】
  - 胡烈的妻儿在洛阳。司马炎许诺：带魏兵回去，旧事不问，士籍还原。
  - 胡烈的选择：他不开关，也不打。他跟姜维做了一笔交易：放所有想回家的魏兵出关回中原，他自己留下守关。「我的名字写在檄文最上面，回去也是死。他们没签过名。」
  - 胡渊要跟父亲留下，胡烈把他打晕了绑上马车，跟着魏兵回去。
  - 回6「士家」母题收尾：老兵也回去了。
- **回32 羊叔子**：羊祜来使，带着夏侯霸的遗孤。羊琇与族兄在两军之间相见。
  - 羊祜：「我来，是替一个死人的孙子看看他祖父死的地方。」议和。三年不相攻。
  - 羊琇终于说出锦囊里到底写了什么：「娘说，遇到姜维，能帮就帮。」辛宪英早就看透了钟会会败、姜维会活。

### 卷六　回天（回33～36）
**卷意**：所有债一起来讨。

- **回33 范长生讨债**（关18 战斗：白水关前哨，或无战斗并入关19）
  - 范长生要的那件事到期：十年不征益州一兵。可晋军三年后必来，不征兵就守不住。
  - 内（汉）：益州人站在范长生一边，荆州旧人站在姜维一边。刘璿两头为难。
  - 丘建在范长生身边当了道士（回28 伏）。
  - 姜维答应了。代价：从此汉军只有陇右、汉中、南中的兵。益州人第一次真正认这个「汉」。
- **回34 白水**（关19 战斗：白水关）【爆发5：杨兰】
  - 晋军试探白水关，姜维守关负伤。
  - 杨兰终于说出那句话（回18 手镯回收）。不是「我喜欢你」，是：「那副手镯，你还留着没有？给我吧，我现在戴得上了。」
  - 诸葛果把画了十年的地图交给刘璿，不给姜维，她说「大将军不需要地图了，需要地图的人是以后的人」。她决定留在成都辅佐刘璿，离开姜维。
  - 落点：杨兰（原作「平起平坐」的回响）：「尹香姐姐，这一回，我们总算平起平坐了吧。」
- **回35 还都**：刘璿即位于成都，改元。向充执旗（回9 手指）。谯周闭门不出，送来一篇新作，题目是《复国论》，内容是骂复国。刘璿笑着收下。
- **回36 再等一阵**（终章，无战斗）：姜维辞大将军，回冀城，尹香墓前，杨兰在旁。「让你久等了。我还得再晚些去。」
  - 最后一条地图文字：史实里的 264 年正月十八，姜维死于成都乱兵，剖腹胆大如斗。「而在这一年的正月，有一个叫夏侯和的人，多问了一句。」

## 六、写作提醒
- 外矛盾写「局」，内矛盾写「人」。同一回里，外矛盾给结果，内矛盾给过程。
- 每回至少一场内部争吵，吵的双方都有理。
- 爆发回的前一回必须轻（斗嘴、闲笔），爆发回的后一回必须低开（小人物收拾残局）。
- 主角的胜利永远要有人买单，买单的人要是读者已经喜欢上的人。
- 史实分歧点要在注脚里讲清「史实如何，本线如何」，落「而在这一年……」。


## 节奏调整（2026-10-15 用户意见 14，自回8 起）
- 一件事最多 3 场（起、转、果），过程用地图文字跳过；主线场次约占一半。
- 每回至少两条吴、魏内斗线，各有输赢：吴写孙休病重立嗣、张布对濮阳兴、孙皓、陆抗与建业；魏写司马炎对司马攸、贾充对荀勖与裴秀、杜预、钟毓一家。
- 后续分卷细案里一事多场的地方，写到时就压缩；省下的场次给吴、魏内斗。
