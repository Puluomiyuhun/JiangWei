## 构建与部署

Python 3.10或以上，无第三方包依赖。从仓库根执行：

```powershell
python -X utf8 project/mod_build/verify_revision.py
```

输出到被忽略的project/mod_build/build，不自动部署或启动游戏。已交付镜像见[project/RS](project/RS/)，最小输入在resources/build-inputs。支持JIANGWEI_GAME_DIR、JIANGWEI_ORIGINAL_RS_DIR覆盖本机输入；默认音频按文件名清单核对，不表示试听。

当前7652对白框静态通过，19R异路径重建一致。杀局初次四R部署后，最新心声修订仅再次双备份更新R09，另18R保持；Data与S未变，未实机。见[部署状态](project/部署状态.json)、[本轮核验](project/杀局心声修订核验-20261018.json)、[复现核验](仓库复现核验.json)。
