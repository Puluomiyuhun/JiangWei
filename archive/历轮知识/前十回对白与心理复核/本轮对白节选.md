# 本轮对白节选

直接节选自本轮正本，没有另写展示稿。主要看个人口吻、私心和信息怎样进入对白；完整背景、CD与站位另见《舞台调度表.md》。


## 第1回·两种人｜句安：嘴上试探，心里另有一番话

```text
[事件名] 两种人
[音乐] 6
[场所] 成都 皇宫外
【胡烈】夏侯和，名单上还有四个人。午前放不放？
【夏侯和】放。各归原营，不必交印。
【羊琇】我营里已经认过人了。司徒要我再进宫议事，我带六个亲兵。六个，不是六十个，他也别叫六百人迎我。
【胡烈】你倒知道怎么讨人喜欢。
【羊琇】娘说人在气头上，先把数目说清。别的客气，以后还来得及。
【句安】诸位能各归本营……末将原先在麴城的那些人，散在几营，可否也让他们认我？
【胡烈】你不是有钟会给的兵么？
【句安】末将不是嫌司徒给得少。只是麴城那些人，跟着末将降过一回……若还有人肯认，总不能连问也不问。
【夏侯和】写名字，交蒋斌核认。别挟着旧情替人答应第二次。
【句安】（肯认才怪。那年挨饿的时候，谁没骂过我？可如今人人都在领自己的兵，我再不张口，往后连个替我回话的人也没有。）
【胡烈】我也正要说这个。今天出宫的，回去各安各营；别一出门，就说所有魏将都跟钟会走了。
```


## 第2回·山道｜家常、旧事与借粮交织

```text
[事件名] 山道
[音乐] 57
[场所] 成都 西山 山道
【姜维】诸葛姑娘，你怎么认得范长生？
【诸葛果】从前带小瞻来过。他刚娶公主那阵子，心里有事，也不肯告诉姐姐，倒肯陪范先生下棋。一坐就是半日。
【杨兰】五斗米道，就是张鲁在汉中那一套？交五斗米，入道，生病了就认错？
【诸葛果】还有义舍，留米肉给过路的人吃。张鲁的旧法，不只收米，也要让人活得下去。山户肯听先生，未必全为求仙。
【杨兰】那我们也算过路的？
【诸葛果】主母身后若没带着十几万人的饭碗，倒可以这么说。
【姜维】先生能作主的粮，有多少？
【诸葛果】得各社自己凑。牛车也要留着下田，不能当成军仓，拿了还叫他们送到天边。
【杨兰】听见没有？这回借不着，不能怪道士不肯替大汉出力。
【姜维】听见了。丞相给我讲关中、陇右的时候多。益州供粮的难处，我也听过，却总想着还能再挤一些出来。
【姜维】（公琰、文伟都在时，粮少一批，我总觉得成都还有办法。如今自己来借，倒也想开口便说非如此不可。先生若这样催我，我肯不肯？）
【诸葛果】到了。主公若还没想好，先喝茶。先生不喜欢客人一进门，就替他安排好要做什么。
```


## 第4回·两条路｜诸葛果：懂得道理，仍然想念弟弟

```text
[事件名] 两条路
[音乐] 57
[场所] 成都 姜维府邸
【诸葛果】主公来，是要说邓艾的事。
【姜维】杨兰告诉你了？
【诸葛果】主母只说主公有话要说，别的一个字也没说。她说这件事，得主公自己来。
【姜维】是。我在绵竹放了邓艾，让他带陇西军回去。他说到了狄道，自己去长安领罪。
【姜维】两万人夹在钟会和卫瓘之间，哪边先拉过去，另一边就要见血。城里还有你们，还有陛下。
【姜维】这些话说得再多，也改不了一件事。杀思远的人，是我放走的。
【诸葛果】邓艾还活着，肯不肯去长安，是他的事。小瞻已经回不来了。主公，果不想替他们两个评谁的道理更好。
【诸葛果】果也知道，那两万人的命，不能拿来给小瞻陪葬。……知道归知道，主公别一直看着我。
【姜维】尚儿那年才十几岁。
【诸葛果】尚儿冲进魏阵之前，跟他父亲说了一句，父子荷国重恩，不早斩黄皓，以致倾败，用生何为。
【诸葛果】他临死还在恨黄皓。主公，成都把他们父子留在绵竹，后来又降了；这笔怨，果也没法只找邓艾讨。
【姜维】………你恨我吗？
【诸葛果】果不恨。只是往后若有人问起，主公别说是为了大局。就说是为了那两万人。
【姜维】为什么？
【诸葛果】小瞻最听不得大局两个字。当年他和董厥、樊建联名上表，要夺主公的兵权，召主公回成都，用的就是这两个字。
【诸葛果】他在九泉之下听见，又要生主公的气了。
【姜维】…好。我记着。
[退场] 姜维
【诸葛果】（小瞻，从前你埋怨主公，我总劝你别那么想。今天他来，我又急着替他说不恨。若你还在，又要说姐姐偏心了。）
【诸葛果】（可你若还在，骂我几句也好。你小时候拿着画来找我，我偏要你先把功课做完……如今再想看看，倒不知道剩下的那些画收在哪儿。）
```


## 第5回·逆水｜陆抗：宫中旧事怎样妨碍今日荐人

```text
[事件名] 逆水
[音乐] 70
[场所] 西陵
【虞汜】诏上许征三万，现能调到多少，须另报。陛下令我沿途察看诸营，先把伤亡和缺额核清。
【留平】步协折了兵，便从都督的营里补？军士已经在问，同是受诏出征，为什么败的一家有新兵，没败的一家要把老底子交出去。
【陆抗】他们担心的不只补缺。步家的军吏留下，陆家的营伍拆开，以后赏罚不知找谁，才是根本。
【虞汜】都督口中也分陆家、步家？
【陆抗】说他们在怕什么，不等于替他们认这个分法。旧将可以带旧部，但不能借此把别营当外人。
【虞汜】我赞成。可你保留自己的旧将，却要步协把败军交出来，建业听起来仍只有陆字。
【陆抗】所以我请步协留领本部，战时听节制；补入兵仍由原将领队，不立刻混编。败将不夺尽，援将不独吞。你肯替我把这两条一并带回去么？
【虞汜】肯。我也有一条：伤兵和阵亡家属先照实登记，不能让前军少报，后军替他填数。张将军问起来，我会照实说。
【留平】使君不怕他不高兴？
【虞汜】孙綝要入宫那日，我也没有因为他不高兴便把门打开。陛下叫我来办事，不是来替谁长脸。
【陆抗】那便请使君与我同看军册。还有几封旧部的家信，想让子弟进京做近侍，托到我这里。
【虞汜】你怎么答？
【陆抗】当年太子孙和与鲁王孙霸争位，先父劝至尊把嫡庶名分定清。他的外甥顾谭亲附太子，也遭了流放。这几家如今又想送子弟进宫，我怎敢轻易写荐书？
【陆抗】可他们来信还叫我幼节，说儿子已经长得比父亲高。先父的旧人一日少似一日，活着的求到这里，我总不能只回一个不字。
【虞汜】有才便荐到该去的职，不许一句世交就送进宫里。你怕人说陆家，便一个不用，也不是公道。
【陆抗】我知道。只是写别人的名字容易，轮到在后面写自己的，手便慢些。
```


## 第7回·七成｜蒋斌与句安：认错之外，还怕丢掉什么

```text
[事件名] 七成
[音乐] 50
[场所] 乐城
【钟会】七成。烧的、运走的，都在这里。句安，你报的是二十车疏散外营；蒋舒给仓吏的副据，怎么成了携原属归魏？
【句安】末将没准他这样写。可是……押了郡印。旧吏怕前事追罪，末将准用一份空白凭据，让他补姓名。
【胡烈】空白凭据！你索性连太守也叫他替你做！
【句安】末将…末将想把他们留下。他们宁肯信魏的赦，不肯信我这新太守。那印盖下去，我还以为，总算有一件事能办成了。
【钟会】所以你就把印交给他们证明自己肯保？
【蒋斌】旧吏复任，是我也赞成的。可我没查清他们与荀恺已经有约。仓册我重核，人由我去认，该问我的罪，别推给一句降将难信。
【蒋斌】（司徒问汉中用谁，我还觉得，总算问到了懂这里的人。那些人见了我，满口都是先父……难道我听得高兴，便少问了几句？）
【胡烈】那就人人分一点，句安仍坐着？
【钟会】句安停郡政，留南郑戴罪督运，不得独用印。蒋舒弃差引敌，追捕。旧仓吏分案查，不许把未从的人一同拘了。
【姜维】余仓由蜀魏两营分守，蒋斌会验。军中减食，先保路上运夫，不能饿倒了送粮的人。
【王含】乐城的人可以护东路，不调去替南郑补空。我已许他们看住家属，军府也许过。
【钟会】我没有叫你调。
【王含】末将先说在前面。
【钟会】……准。此案我许可过以粮疏散败兵，不能都说是句安自作主张。军府的文书也查，凡报只须给粮便能安定的，一个别省。
【姜维】剩下的粮不足北征。得等成都转运。
【钟会】剑门两方合署，本为防谁独占归路。如今若两方不肯同署，也能把一军拦在这里。樊建处发急书，把供给条件谈清。
```
