# 前十回结构修订 · 使用说明

- 阅读完整正本：`姜维传·钟会线·长篇.md`。
- 优先看这次最重要的改动：`前五回重点阅读.md`。
- 改了哪些：`修订说明.md`、`逐场修订索引.md`。
- 制作：`舞台调度表.md`、`静态校验.json`。
- 交接：`交接记录.md`。

顶层 `RS` 是本轮完整 R_00.EEX—R_09.EEX，十个文件为一组。首回含原作 R_33 第18—34块原字节前情、新游戏初始化及第一回；末回停在第十回待续。目录中不含 S 战斗文件，战斗处有明确占位提示。本轮没有部署。

Data.e5 与当前测试游戏一致，无需替换。构建器会在 `mod_build/build` 生成一份供比对，不能因此认定必须覆盖游戏 Data。

`mod_build/draft/ch1.md`—`ch10.md` 是分回副本；当前构建器读取根目录的长篇正本。后续若直接修改分回稿，须同步长篇再构建，避免只改副本未生效。七回短版 `姜维传·历史线续·钟会线.md` 仅供旧解析器校验标题，内容已过时，不能当成本轮正本或拿来覆盖后续回目。

本机静态复核入口：`mod_build/verify_revision.py`。使用现有 Python 与源码 tools 依赖，脚本会在本包内重新构建并校验，不修改游戏。构建路径仍指向 F 盘现有测试游戏、引擎工具及原版备份；换机器时须先改路径。

后续若部署，应先备份游戏同名十个 R 文件，再复制顶层 RS，并逐文件核对 SHA-256；不替换 S 和 Data。此前停在旧版待续处的存档不保证兼容新结构，建议从新游戏或较早的合适进度开始检视。未实测游戏运行，本包不承诺旧存档能无缝恢复。
