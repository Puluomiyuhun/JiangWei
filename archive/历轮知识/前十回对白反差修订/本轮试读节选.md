# 本轮试读节选

均已写入本轮正文，不是独立样稿。选四处，分别看重伤相见、熟人相处、魏营公事与战后强撑。

## 第10回《城里没有三千人》

```
[事件名] 城里没有三千人
[音乐] 39
[场所] 永安
【罗宪】杨宗？……怎么抬着回来了？放下，慢些！
【杨宗】将军，援兵出了。两路，合两千三百。
【罗宪】先别说。医者呢？
【杨宗】叫过了。末将怕外头还传三千，先来报一声。
【罗宪】（腿上那块布……血都结黑了。别当着他问，医者来了再说。）
【罗宪】从哪边回来？
【杨宗】北坡。大将军仍在汉中，廖将军、杨将军领兵。末将等到发兵回报，抄了实数，便先走山路。
【杨宗】（总算说清了。将军还在看我的腿……要是先叫他抬进去，又得等他来问。）
【罗宪】到了哪里，信上写了没有？
【杨宗】巴西有警，正在改道。日子不敢许。将军，这回是真有人往这里走了。
【罗宪】嗯。城里不再传三千。
【罗宪】（两千三百，还在改道。这样便够了？我竟也松了口气……先前骂他只带回一个期限，现在又盼着他说一个准日子。）
【罗宪】陛下的回书呢？
【杨宗】在行囊里。陛下没说要我们反魏，也没说把城交给钟会。叫我们活着。
【罗宪】……都听见了？这句话，传下去。
【罗宪】（当年把我赶来时，哪肯听我一句。如今倒又惦记着我……陛下，臣还能怨您多久。）
【杨宗】将军，那张纸还在？
【罗宪】换过几张了。别找，在我这里。
【杨宗】今天划了没有？
【罗宪】还没。先送你进去。
【杨宗】给我划吧。今天是我回来的日子。
【罗宪】你这手抖得……等医者来，看过再画。
【杨宗】没喝酒才抖。将军留的那份，可别忘了。
【罗宪】库里早没了，你还惦记！
【杨宗】那先欠着。笔给我。
【罗宪】（还有心思讨酒，兴许养几天就好。都撑着回到城里了，总不至于……）
【罗宪】……给他笔。我托着，别动。
```

## 第8回《一支箭》

```
[事件名] 一支箭
[音乐] 39
[场所] 乐城 姜维住处
【杨兰】果儿，这箱子也太沉了。破地图、断马鞭……这支箭也留着？
【诸葛果】主母，那支别动。
【杨兰】锈成这样，还能用？
[登场] 姜维
【姜维】放着吧，杨兰。
【杨兰】我又没折它。你收这么多东西，倒舍得把自己的马送人。
【姜维】段谷那一仗，邓艾射在我马鞍上的。
【杨兰】……是那一支。
【姜维】死了一万多人。我有时找地图，看见它，就想起那时候。
【姜维】（方才她若真扔了，我还是要捡回来。可我也盼过，哪一天不必一开箱就看见它……）
【杨兰】我把它包起来，别把手扎了。
【杨兰】（我还当是他从哪儿随手捡的。早知道就不问了，偏又当着果儿。现在说什么，他都要以为我在劝他。）
【诸葛果】包箭的布，放在这里吧。
【诸葛果】（再说段谷，他今晚又不肯歇了。主母方才也有话没说完……拿那件战袍逗她，她该要恼我了。）
[音乐] 34
【诸葛果】主母也留着东西。主公在洮西划破的那件战袍，主母一直压在自己箱底。
【杨兰】果儿！不是叫你别说么！
【姜维】我找过两回，还当丢在军中了。
【杨兰】袖子没缝好。等着吧，找着了也不给你穿。
【姜维】那我不找了。
【诸葛果】（还好，笑了。主母先前缝坏的那一回，便不必再告诉他了。）
```

## 第10回《把诏办成》

```
[事件名] 把诏办成
[音乐] 22
[场所] 荆州 魏军营帐
【陈骞】诏书准了。荀勖把准许的事逐项列了，连援军伤卒不改军籍都写上。你们去永安，先送粮，再宣诏。
【主簿】前军请随粮船进一部。几位将军说，出了兵，总不能连城门也不进。
【陈骞】不准。我的行令附在诏后，写明粮船先入，兵不入城。
【主簿】他们还报了入城后的守门人选。
【陈骞】（人都挑好了，才来问我。城没接到，先把驻军的缺占上，荀勖那边怕也有人去说过了。）
【陈骞】退回去。罗宪既能挡住陆抗，就不是看见魏旗便肯交门的人。谁嫌留在船上没有功劳，换人去。
【主簿】属下照传。伤卒疗养以后，原跟钟会的，也都准归？
【陈骞】准。诏上有的话不再改，行令留副给罗宪。别到了城下，又另议一套。
【主簿】功簿上先按运粮记，还是等入城的军报？
【陈骞】先记运粮。肯办这差事的，该得多少就给多少，不必非等他们打一仗。
【陈骞】（都想带兵进城。我若也年轻二十岁，未必肯老实送这一船粮……可这回真把人逼得关门，挨相国骂的是我。）
【陈骞】回表给相国，另抄一份入御前。人数、伤亡，照实写。
【主簿】御前也要？
【陈骞】陛下特意问过。让他知道这道诏已经办下去了。
```

## 第10回《接到的人》

```
[事件名] 接到的人
[音乐] 31
[场所] 永安
【罗宪】廖将军，杨将军。城里还能安排伤卒，先把人抬进去。
【廖化】后面还有人，南边能不能再出一队？
【罗宪】出过了。吴兵已经合围，再出，就是从里面往刀口送。
【杨兰】别出了。我最后看见的那一队，是步协的旗。后队散在坡下，能藏的会藏，城门口再打起来，他们反倒走不动。
【廖化】那就把他们留在外头？！
【杨兰】我带来的八百，也有一半没点着。
【杨兰】（别再喊了。那几个替我守后队的，我连一个也没看见。再听他说出去，我怕真忍不住……）
【杨兰】先等天黑。城门口别再打了。
【廖化】……
【杨兰】他们若在坡下躲着，等天黑还能走。我们把吴军全引到城门口，连这点空隙也没了。先等一等，好不好？
【廖化】…先点名。
【罗宪】将军，此番带来的粮，够几日？
【廖化】后船还在路上。随身的，也多分给伤兵了。
【罗宪】城里现有的，只够合在一起再撑数日。箭多了，粮却少了。
【杨兰】钟司徒的书在这里。给罗将军的，不是调兵令。将军自己看。
【罗宪】我会看。军中先别按汉、魏分口粮，来的都一样。
【廖化】罗将军！我们冒死来援，是来守汉家的城，不是来争一口饭！
【罗宪】我知道。老将军，先照这个数发下去。有什么不够，再来找我。
【罗宪】（连他们也没带够粮。我方才还想，只要人进了城就好。……不能在这时候叫他们听见我发愁。）
【杨兰】杨宗呢？我替大将军问他一句。
【罗宪】昨夜没了。
[音乐] 109
【廖化】…昨夜？
【罗宪】他回来的时候，城里问来了多少人。他报了两千三百，叫城里别再传三千。说这回是真出发了，不只是他替大将军说好话。
【杨兰】……把他的东西给我。回去时，我带给姜维。
【杨兰】（我还想回来告诉姜维，没他跟着，我也能把事情办好。如今该怎么开口？杨宗连我到城下都没等到，我倒还惦记那一句夸奖。）
【罗宪】这双鞋带去。纸留下，城里的人还要看。
【廖化】纸？
【罗宪】每天一道。他昨夜添的那一道，歪得厉害。叫我扶着，我没扶稳。
【罗宪】（我还骂他贪酒。人都回到城里了，我还觉得明天可以再骂他…哎！）
```
