# 开局为何脱险：本轮修订说明

前版的问题在于：写出了几项安排，却没有让读者看见每个人在作决定前，如何比较继续攻城、放人、等待的代价。读者只能自己把“保旧属”“只守营”“联署”翻译成实际利益，最重要的成功逻辑反而藏在术语后面。本轮将这些因果写回现场对白、心理活动与验人回报，不让说明文替正文补洞。

这里的成功，先是免于当夜覆灭；魏军尚未整体变成钟会的叛军，蜀汉也尚未复国。后面的每一步另有条件。

## 历史、原作与架空改动

《三国志·钟会传》记载：囚将、改由亲信领军后，胡烈经亲兵向外传出坑杀说，诸军自行鼓噪赴城；钟会获报后与姜维商议应敌，并下令杀被囚诸将，最终守御崩溃。不能把失败简化为“胡渊只信了一个坑的谣言”，也不能以“辟谣一句即可救全局”作为本稿翻盘依据。[《三国志》卷28](https://zh.wikisource.org/wiki/三國志/卷28)

原作游戏R_33则用《临门一脚》《远大的计画》《郭太后遗命》《事机败露》等场，写出夏侯和逼反钟会、姜维企图借杀将使钟会依赖蜀军，再乘机复国；兵变后又有蒋舒救卫瓘、外营取得号令的过程。以上角色安排属于游戏叙事，不能全部当史实。

本稿沿原作17块接入，新增分歧发生在外营尚未齐集、城上尚未发箭之时。夏侯和提前揭出丘建旧属关系，争来重新决定的时机；这还不足以自动成功，后面仍须真放人、能核验、留自保能力、停止强迫署檄。今夜能够停住，是本稿所给条件下各方暂时有利的选择，不是证明历史上照此必能复国。

## 当夜的完整因果

1. **魏营为什么会一起动？** 主将被关、不能相见，坑杀传言使军士担心自己也要死；胡渊先举救父之旗，使别营敢跟着救自己的将。没有统一接到的朝廷调令，也不是所有人都先同意由胡家统领讨钟会。
2. **为什么还有谈的机会？** 本稿把干预放在诸营尚未会齐、双方尚未见血时。钟会先禁射、禁杀被囚将领，未让传言变成所有人都看见的杀戮。错过这一刻，仅靠好话便很难把正在冲门的人叫住。
3. **钟会为什么肯放？** 扣着胡烈，胡营必继续来救；只在城楼亮相，像逼人质说话。真放回本营仍可能反攻，但至少让对方有了可选择的停手机会。钟会保自己的门与亲兵，留卫瓘在宫中，未把全部指挥权交出。他承担风险并让出逼签名的手段，不是突然相信胡烈忠心。
4. **胡烈为什么出来后不杀钟会？** 自己已经有兵、有刀，明日反悔仍可再来；现在冲，会危及仍在宫里的诸将，也把胡渊从救父的带头者变成继续攻宫的责任人。监军只证实停争、还营，暂不署反司马檄，因此胡烈还可以向长安报事、等命。他得到了当下所求，却没有交出下一步的选择。
5. **为什么旁营也等？** 羊琇独立回营叫停；各营自己选亲兵进去见自家主将，见完能回来，不靠胡烈代他们担保。正文让第一批亲兵真的带回书和消息，胡渊亲自去问。每一营的将校重新能够管自己的兵，旁营便未必肯再跟胡家一起冲。
6. **为什么不是纸上军约一签就天下太平？** 暂停署檄、保留兵械旧属、蜀军不入魏营，都是先改变实际控制，再写明承诺。胡烈明说不按时放齐便再来，庞会仍不肯离开关家附近，卫瓘仍准备通涪县，丘建仍只求自保。冲突没有被取消。
7. **姜维到底付出了什么？** 他放弃“杀魏将、魏军自行散去、再除钟会”的原计。魏将活着且掌兵，钟会也不再只能依赖蜀军，速成复国之路变难。换来的是城中旧主、百姓、旧军活过当夜，并有机会重聚蜀军、同钟会谈实际需要。

## 第一至五回如何接成一条线

| 阶段 | 新写明的动机与条件 | 不能误读成 |
| --- | --- | --- |
| 第一回停兵 | 真放人、各营验人、不缴械、不强签；各方有自保能力，军士不必马上攻城才能活。 | 十几万人已经忠于钟会，或胡烈一句没有坑便能命令所有人。 |
| 第二回暂留 | 军士需要饭，留营才能继续等归途；杜预、荀恺也提供接兵与粮，使他们仍有另一种选择。 | 姜维借到米便收买全军忠心；句扶三千兵武力压住十几万人。 |
| 第三回陇西军北还 | 邓艾仍在押、护送可核、旧营不拆、归途有粮；钟会承认这两万人不能算自己的兵。 | 邓艾被感化归附、姜维偷偷赦囚，或陇西军交给蜀军指挥。 |
| 第四回分类合作 | 胡烈怕先交兵受问、营众散去，冒险署共讨；羊琇仍等家书，只守营；卫瓘只作见证。 | 同一篇伪诏突然变可信，所有人都有相同最优选择。 |
| 第五回不再全营相攻 | 庞会案只论夜袭、缚兵，不能把拒署当死罪；胡烈求情失败仍保住庞营旧属与免连坐。 | 斩庞会人人心服；旧怨消失；签字便让魏将失去军队。 |

第四回胡烈的选择尤其要保留风险：他并不知道司马昭必杀自己，卫瓘也当面反驳“受问不等于定罪”。他对被夺兵、家属受问与儿子责任的恐惧，使他选择一条可能更坏的路。羊琇不同意他，胡渊也追问母亲怎么办。让观众懂他的算盘，不等于替他证明算盘一定正确。

## 本轮实改

第一回整场重写《旧主》《忍数日之辱》《没有坑》《城下》《下一步》，第四回重写《两条船》。其余相关场景补入决定前后的心声和对手的判断。没有增加scene，也没有将一件事再拆几场。第一回对白由约9200字增至约1.15万字，增加的主要是关键决策过程。

同时修正第二回仍叫“发完归营令”造成前回还营未完成的误会；明确邓艾本人仍在押赴长安，旧部另行北归，避免《放虎》《两条路》旧概述让人误以为邓艾已被放回狄道。

第六至十二回正文和R文件原字节保留。本轮为原有结果补足过程与动机，没有新造一支援军来解释脱险。
