# 第十一回试读

一场南中议事与一场归来相见，完整回目另见《第十一回·南中.md》。

```
[事件名] 三千人的来处
[音乐] 0
[场所] 南中 建宁 官署
【孟琰】霍都督，诸家的意思我带到了。不是不给兵，是北边须有个说法。先降魏，再反魏，打完吴人又叫魏人进城，这到底是怎么个打法？
【霍弋】永安的事，关索已经告诉你了。罗宪开门收粮，不是姜维叫他归魏。
【孟琰】郡里人哪里分得这么细？他们只晓得出了兵，回来的少，旧主还是没做回皇帝。
【花鬘】孟大哥，别把大家都说成一样。也有人愿意去，只是怕被拆散，送到不认得的将军手里的啦。
【孟琰】我知道。你前天去说，他们便答应；我昨天去问，才说家里还等着今年的收成。
【花鬘】（又说我不懂家里的事！老爹死后，留在这里收拾的是孟大哥，这我认。可我带出去的人，也不是一个没带回来呀。）
【关索】老孟，这三千是都督麾下的官兵，不是叫你孟家凑三千。你们要免十年租，是替军户求，还是连自家田也一并免了？
【孟琰】都有。你不用替我说得好听。
【孟琰】当年丞相用南中大姓管部众，粮马也向诸家取。现在有事了，叫我们管；要论赏赐，又只认朝廷的册。没这么省事的啦。
【孟琰】（关索在外头还能叫一声关将军，我留在这里，族里填不上的窟窿都来找我。花鬘一句认大将军，倒把我衬成了不肯出力的人。）
【关索】（这黑脸以前也替丞相打过仗，不是见钱便想反的人。可他如今守着孟家的田、孟家的寨，说一句肯，身后不知多少人要来骂。我再拿老交情压他，也只会叫他更恼。）
【霍弋】十年我不答应。我这个都督能当几年都不知道，拿十年租赋哄你，你还真信？
【孟琰】你不答应，爨谷便有别的去处。吕兴又来求援了，交趾许给他的可不止几车粮。
【关索】他想去当太守？
【孟琰】想。南中的人领兵去了交趾，地是自己打的，吏也由自己用，总比到汉中等钟会赏脸强。
【霍弋】吕兴也没说让位给他。那边刚杀了吴国太守，又要请一个太守去？爨谷先把人家的原书拿来，别只叫族里传好听的。
【霍弋】（爨家有兵有路，孟家也有。这两家若合起来，郡里的印还在我手里，我也只能坐在这里盖印了。）
【花鬘】那就把愿意北去的人先放出来。孟大哥，你不能一面说他们不愿，一面不许他们自己来。
【孟琰】你去问，他们敢说不？你是孟获的女儿，关索又站在你旁边。说一句不去，明年寨里的事还找不找你们？
【花鬘】（我刚才还真想，当着我的面，他们总肯说实话。可我若不高兴，他们看得出来……以前跟着老爹出去，别人不也这样看他的脸么？）
【花鬘】……那我不在旁边。让都督的人问。
【关索】我也不在。你挑两个人来看着，但不许站在人背后记谁先开口。
【孟琰】好。还有军户今年的租，先免了，不是打赢了再免。死人家里等不到领赏的日子。
【霍弋】出征军户，免今岁租役，直接给到户里，不能算成你们诸家的领赏。我留在建宁办。
【孟琰】诸家出粮呢？
【霍弋】先付一部分，余下记债，拿都督府自己的岁入还。十年全免不成，别的还可议。
【孟琰】你府里哪有这些钱？
【霍弋】赌场还没卖。
【关索】……你来真的？
【霍弋】不真。卖了也填不上！先别替我感动，谁肯出粮、多少现钱，下午把账拿来，再算。
【霍弋】（这几个家伙还真信我能一把捐完。我舍得，他们也得买得起才行。先拿一处产业抵着，剩下的要向成都讨，不能每回都叫南中人自己养着北征。）
【花鬘】可他们先前领过北上的令，如今又问愿不愿，会不会以为你连官兵也管不住了？
【霍弋】会。所以不散营，不叫人拿着军械各自回家。愿去北方的另点，不去的仍守南边，谁也别说守交趾的路不是当兵。
【孟琰】这还像句话。我再去跟爨谷说。
【孟琰】还有，花鬘。你若北去，别再替大将军把后面的兵也答应了。南中不是只留你一个孟家人。
【花鬘】我知道的啦。可是你也别每回都拿老爹来压我。老爹要在，今天未必肯听你的。
【孟琰】他当然不肯。他连我当年去北方，也骂过。
【孟琰】（她那时还小，只记得父亲最后肯了。前头那几个月怎样闹，我又何必每次都拿来说。）
[退场] 孟琰
【关索】他还是肯出粮的。
【霍弋】肯出一份，不肯把家当都押给我们。别替他答应第二份。
【花鬘】我去看北营。关索，你今天不许跟来。
【关索】刚答应不站在人旁边，你就忘了？
【花鬘】我去告诉他们不用看我的脸色！……算了，叫别人去。烦死了的啦。
```

```
[事件名] 先出去走走
[音乐] 57
[场所] 乐城 姜维住处
【诸葛果】外间还在议事。杨将军先歇一歇，果去叫主公。
【杨兰】别叫。我回来以后，到哪里都有人问还能走几个、留了几个。你也让我先坐一会儿。
【诸葛果】好。茶已经凉了，果另换。
【杨兰】凉的正好。……果儿，你怎么瘦了？
【诸葛果】没有。是换了件衣裳。
【诸葛果】（她倒先看见我了。一路上怎样，我还没敢问，怕问得同外面那些人一样。可是只说茶，她又会觉得我在躲。）
【杨兰】你想问就问。没有伤到筋骨，肩上挨了一下，早收口了。罗宪替我找的衣裳大了，别看我像从别人箱子里偷出来的。
【诸葛果】肩上？信里没有。
【杨兰】信是给姜维的，又不是给他的伤药铺。什么都写，他下一封便只问伤了。
【诸葛果】果原也只想问这一句。
【杨兰】……哦。那你看吧。门关上。
[移动] 诸葛果 47 58 3
【诸葛果】已经收了。只是这里还磨着，果拿块软布垫上。
【杨兰】你别跟他学，一伸手便先皱眉。好像我出去打了一场仗，就做了什么对不起自己的事。
【杨兰】（其实方才看见城门，最想的就是他赶快出来。可真要让他当着众人的面扶我，我又要嫌他了。怎么这样难伺候，连我自己都烦。）
【诸葛果】主公没有叫果来劝你。他这几日也怕见你。
【杨兰】他怕什么？我又不是回来找他算账的。
【诸葛果】果说不好。他将你那句不许找奸细，看了好几回。
【杨兰】（我写时只顾痛快。他一个人对着信，怕是连还嘴的地方也没有。……活该，谁叫他从前总把话说完就叫人退下。）
【杨兰】鞋已经交给宁先生了。杨宗的。收殓用的是城里新做的，这双旧的，我没丢。
【诸葛果】嗯。
【杨兰】果儿，我本来有好多话要骂，路上想得很齐。见了你，反倒想不起来。
【诸葛果】那就等想起来再说。果今日都在。
[登场] 姜维
【姜维】兰儿。
【杨兰】议完了？
【姜维】还没有。义权先接着。
【姜维】（我站在门外，居然先想好一句路上辛苦。这是叫她来报军情么？她说不许摆那张脸，我连自己是什么脸色都不知道。）
【姜维】我想陪你坐一会儿。
【杨兰】屋里闷。到外头走走，行不行？
【姜维】行。
【诸葛果】果把茶收了。两位不用等。
【诸葛果】（真走得这样快……果还想问她一句，夜里是不是也睡不着。下次再问吧，不必每一句都赶在主公前面。）
[退场] 姜维、杨兰
[场所] 乐城 城外
[音乐] 107
【杨兰】往这边。别一出去又绕到军营。
【姜维】我知道。
【杨兰】你不知道。上次说陪我走走，走到后来，多了两个参军，一个修弩的，还替人看了半座营。
【姜维】那次恰好遇见。
【杨兰】今天遇见了，你就说不认得。
【姜维】……这恐怕瞒不过去。
【杨兰】那就少遇见。你看，前头不是还有一条路么。
【姜维】好，走这边。
[移动] 姜维 45 51 1
【杨兰】慢一点。我只是想出来，不是要跟你比谁先到。
【姜维】手给我。
【杨兰】哼。这个倒不必教。
【杨兰】（在城外想着见他，见了又全说这些闲话。可他真肯陪我绕一条没什么用的路，我倒觉得……这一路没白盼。）
【姜维】明日要见的人，先让宁先生替你回。你想什么时候见，再叫他们来。
【杨兰】明日下午吧。今天留给我。
【姜维】今天留给你。
```
