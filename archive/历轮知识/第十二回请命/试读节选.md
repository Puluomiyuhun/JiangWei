# 第十二回试读

两场人物相见与家常：各自影响留守、出行和随后的人际局面。完整回目见《第十二回·请命.md》。

```
[事件名] 关家的门
[音乐] 39
[场所] 成都 关府
【关索】比我记得的矮了。
【关彝】门楼修过。父亲在的时候，嫌旧的漏雨，拆掉了一层。
【关索】我上次回来，你父亲还……
【关彝】叔父已经很久没来了。
【关索】是。我来晚了。
【关索】（路上想了一肚子话，站在门下，开口先说门矮。孩子若问我这些年在哪里，我又要拿南中忙来搪塞么？）
【花鬘】东西先放这里？有些是给家里人的，不是都给你一人的啦。
【关彝】婶母放着，我让人收。叔父，庞会没有屠了关家，您别一直这样看我。
【关索】我知道。只是那夜……
【关彝】那夜我也怕。我后来送了棺材，营里有人收了，没砸。
【关索】你送的？
【关彝】大将军没有叫我送。您若要怪，怪我自己。
【关索】我不怪这个。
【关索】（他倒先替姜维挡一句。这些年该教他的，我没教；真到性命关头，站在门外的也不是我。如今才端出叔父的样子，他凭什么听。）
【关彝】那叔父这次带兵来，是留下，还是去汉中？
【关索】还在议。你若想留成都，我去跟伯约说。
【关彝】我不留。
【关索】先别急。我没说叫你躲在家里。
【关彝】可你们一问我想怎样，就只问想不想留下。家里出了事，我就该一直守着这道门么？
【花鬘】让他把话说完。关索，你自己年轻时，也没肯一直守在家里的啦。
【关索】……好，你说。
【关彝】我跟大将军去过乐城。第一次杀人，吐得连刀都拿不住。后来能拿了，也没觉得自己忽然成了祖父。
【关彝】我想继续去，不是为了叫人说关家的孩子没丢脸。那些跟我一起进城的人，好些还在北边，我不能一回来就全不见了。
[登场] 胡渊
【胡渊】关彝，董尚书叫我送句话。后日议宫外换防，关府的人可以来听，免得又传是把庞营放到你门前。
【关索】胡渊？
【胡渊】是。关将军，我爹让我依原礼见蜀中旧臣，你若要骂我，先让我把话带完。
【关索】谁要骂你？
【胡渊】……那更好。庞营说，他们不往关府巡，只肯认朝廷调防，不肯被拆到别营。
【关彝】我也没请拆他们。
【胡渊】我知道。他们还要防着你家，说南中一千八百人一到，就要找旧账。
【花鬘】我们的兵不是关家的家兵！
【关索】（她这一句说得对。我若为了给孩子撑腰，真把南中兵带到门前，孟琰那句你替谁用兵，就一点没冤我。）
【关索】你替我告诉他们，南中兵先听都督与旧主的命。关家的仇，不拿他们来报。
【胡渊】这句我带到。还有，收棺材的那个老卒说，哪日关公子愿见他，他有话想当面说。
【关彝】他要什么？
【胡渊】没说。我没替你答应。
【关彝】后日叫他一起来。府门外见，不带刀。
【胡渊】好。
[退场] 胡渊
【花鬘】你不怕见了以后，又吵起来？
【关彝】怕。他肯收我家的棺，我想知道，他现在还怎么想。这次叔父在，我不是一个人。
【关索】……我在。
【关索】（总算有一句，不是叫我替他走开。我若还想着只把他领回家，也实在太省事了。）
```

```
[事件名] 去长安的路费
[音乐] 5
[场所] 洛阳 羊祜府
【夏侯霸】叔子，车备好了没有？
【羊祜】岳父还没有获准离洛阳。车先备了，也不能出关。
【夏侯霸】老夫知道。问的是车，不是叫你今日偷开城门。
【羊祜】（前次说随口问路，这回说只问车。真等官文到，他怕是连要去见谁都先约好了。还是把话问在前面。）
【羊祜】长安的消息，您看完了？公主没有被治罪，府门与书信加了查验。现在去，并不能替她少一道守卫。
【夏侯霸】她没有传诏，这件事我能作证。我当初叫义权去逼钟会反，不是受她指使。
【羊祜】您若当众这样说，先受问的是您自己。
【夏侯霸】我不去跟满街人说。上表请见，旧日同郭太后宫中来往的事，可以问我。至于我弟弟那一笔，相国要问，就当面问。
【夏侯霸】（说得倒像我真只去领问。可若一直在这里，公主见的是司马昭，义权跟的是钟会，曹家那些旧人只怕真要以为，夏侯家的老东西吃饱便不动了。）
【羊祜】您要去给公主添一个可商议的人。
【夏侯霸】是。她那里不只缺一个证人。
【羊祜】那我不能替您写成一路养病、绝无旁事。相国日后若问，替您署保的人都会被牵进去。
【夏侯霸】不替我保。你就如实说，我请求赴长安候问，不往蜀中，不带旧部。到了那里，还肯不肯让我见公主，是他自己的胆量。
【羊祜】这最后一句，也不必写。
【夏侯霸】哈哈……不写。老夫还没糊涂到要靠一封表骂赢他。
【羊祜】（笑得出来，倒像已经走出门了。我的妻子若知道她父亲又要往险处去，先怪的仍是我。可我若替他关住，往后他连一张纸也不肯给我看。）
【羊祜】表我递。行装少些，先带御寒的，别只拿刀。长安不是一天两天便能回来。
【夏侯霸】钱也借一点。
【羊祜】府里给您备路费。
【夏侯霸】不是路费。若见到许家的人，老夫总不能两手空着。许仪那孩子……我当年还说，他跟着钟会出去，总能挣些功。
【羊祜】我备一份，不署羊家的名。
【夏侯霸】署。你愿意帮人，不必总借老夫的嘴。
【羊祜】……好。
```
