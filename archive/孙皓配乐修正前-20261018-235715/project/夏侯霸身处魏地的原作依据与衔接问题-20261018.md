# 夏侯霸为何出现在魏地：原作依据与现稿衔接

2026-10-18，针对用户疑问核对。结论：夏侯霸降蜀没有被撤销；原作后续写他段谷受伤获救、藏居洛阳，不是重新投效司马氏。现稿有承接依据，但首次登场没有清楚唤回这段前情。

- `references/姜维传原文/S_24.txt`：夏侯霸与关统为撤军殿后，夏侯霸负伤。R_25《姜维的痛悔》仍报他下落不明，朝廷后续有战死说法，不可据此当成实际死亡。
- `R_25.txt`，173行起《奇迹的生还》：皇甫谧医治中箭的夏侯霸；夏侯和闻阵亡消息来寻，发现兄长生还，承诺保护。父亲旧甲帮助挡箭。兄弟说到羊家婚姻关系及夏侯和在司马昭幕府的处境。
- `R_27.txt`，978行起《洛阳震动》：地点明确为“洛阳夏侯家 地窖”。夏侯霸说自己已经躲了快四年；得知曹髦被杀，仍恨司马氏，并请夏侯和通知曹绫避险。
- `R_28.txt`，634行起《翁婿相见》：同在洛阳夏侯家地窖。夏侯霸指出，夏侯和之外，还有女婿羊祜的泰山羊家势力与司马家姻亲关系，使司马氏默许他留在这里。他仍为姜维担忧，特别警惕邓艾。

这里说的是游戏原作设定，不当作正史结论；不需要另编一次“重新降魏”解释所在地。

## 现稿沿用与新增的分界

- 第2回／R_01《女婿》已经把夏侯霸安排在洛阳羊祜府，写了羊家保护与外界查问，也写他关心夏侯和、姜维。但没有先点明段谷受伤、皇甫谧救命、洛阳藏身的前因。
