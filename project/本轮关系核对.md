# 东吴关系修订核对

通读十三回中27个吴方出场场景，修改其中22场、37处，正文净增419个字符。没有增加回目、人物或新场景，优先替换含糊心声，不靠继续增添势力填满场面。

1. 第二至六回：张布、濮阳兴共同出兵；张要保所荐步协，濮要核实府库支出。丁奉反对抽空守军，华覈担忧毁盟，二者不是自动组成反张阵营。
2. 第三至八回：陆抗、留平支持战后归营；步协要补缺，鲁淑要留懂水路的人。陆抗准一趟借用，不替步协永久放人。虞汜可联署实报，但拒保荐陆家旧人入东宫。
3. 第五回：陆凯、华覈、韦昭因进言受阻而结交。陆凯希望他们以后肯帮陆抗说公道话，并未买来无条件支持。
4. 第九至十回：张濮因太子亲疏争下一朝；丁奉不许两家私换宿卫。施绩反对继续抽江陵守军，却仍送粮给陆抗。张布利用各营自报拉拢留平；留平缺粮求助，有自己不替人歪报的底线，未写成已经投张。
5. 第十一至十二回：陆凯、华覈争停征；薛珝借这道政策和陶璜旧交招抚交趾；张布担心被查荐吏、被换人。薛陶与陆抗因阻止南中援吕兴而合作，各自要办成的事不同。
6. 第十三回：万彧利用张怕失势、濮怕丢相位来促迎孙皓。新君暂用两辅，也通过万彧传令、宫中出钱建立自己的恩信。军中欢迎拨粮不等于已经反陆抗。

校正前后不一致：陆凯统一为陆抗族兄，参照前第四回与本地《陆抗传》R_07、R_16称谓；虞汜由孙休遣出；各营分报由孙休准许，张布借此许催赏。删去一处人物尚未说话，别人心声便准确知道其要求的跳步。
