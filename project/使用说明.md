# 当前项目使用说明

最新：十三回可读性与文风复核修订，十三回209场。阅读本轮修改看 [修订说明与试读](可读性修订说明与试读.md)，接续看 [交接记录](交接记录.md)。

仓库根运行 `python -X utf8 project/mod_build/verify_revision.py`，默认使用仓库最小输入，无需原电脑盘符。构建结果在mod_build/build，核验过的R镜像在RS。命令不会运行游戏，也不会部署。本轮已编译、未覆盖游戏，具体见部署状态.json；部署记录.json是上轮历史安装记录。

检查限静态：对白、分框、人物在场、斜角路径、跳转、原作接入和待续守护。实际动画、遮挡、存档未试玩，S战斗仍占位。完整跨电脑说明见仓库根README。
