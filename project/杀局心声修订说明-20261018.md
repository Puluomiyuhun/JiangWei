# 宁随杀局：心理活动与对话节奏修订

2026-10-18。用户反馈：“应该多一些心理活动，钟会姜维都应该多一些，俩人对嘴感觉太僵硬了。”

## 本轮改法

- 《先别替我担》补钟会的不满与姜维的误判：钟会在意宁随能直接说动成都；姜维因他肯先出粮，以为还能慢慢商量。这使次日杀令对姜维更有打击。
- 《刀已经领了》让姜维先看见宁随伸手被绳扯住、手在抖，再压住怒火。救人时，他知道胡烈只是来问军约，不能把对方当成无条件同盟；也知道驻吏会伤害追随自己的旧部对他的信任。
- 钟会知道原书没有截粮，仍借题要命。他以为姜维终究离不开他的兵；见姜维带胡烈来，先感到被针对，继而算出强杀将换来更大掣肘。放人因可取得实际控制权，杀意没有改成表演。
- 将粮所条件拆成问答：谁来、是否常驻、核粮有什么边界，由双方的质疑逐步说出。关键处有观察、迟疑、接笔与避开目光，避免两人轮流念完方案。
- 救人后，钟会对姜维的冷淡有不快，却舍不得退还刚得到的权力。姜维等绳子解开才敢喘气，并想到自己也曾借钟会的刀谋事；他没有因此原谅杀局。
- 《纸上没有那个人》补姜维的晚间心声：次日仍须与钟会同案议事，不代表彼此信任恢复。能继续合作与伤痕仍在同时成立。

心理活动是角色此刻的判断，不是全知事实。姜维认为钟会算计了自己的救人方式，是现场推断；钟会此前估计姜维离不开自己，随后被实际抵抗迫使改算。不能倒推成钟会从头只想演戏、早已安排放人。

## 持续写作要求

对白中的政治立场要易懂，也要有人听见之后的反应。心声应补嘴上不能说的怒气、惧意、依赖、自负、误判或取舍，让下一句话从这些反应里长出来。不要只把刚说的条款再解释一遍，不要求每句台词配一段独白。钟会的情感不能洗掉恶意，姜维的克制也不能写成没有恐惧、愤怒和私心。
