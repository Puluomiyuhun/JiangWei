# 乐城S样关·贾充实体修正版

## 本轮修复

上一版只在对白里写贾充，没有将他列入敌军部署，并在王含交涉时立即宣布其逃走，导致主城没有实际主将。这是样关实现遗漏。

现将Data已有的100号贾充部署在主城(20,11)，用坚守方针，能在范围内参与战斗；周围及后方原有步兵、弓兵、策士、补给士保持。交涉、第3/6回合调兵、接回全部旧卒，都不会让贾充离场。只有他兵力归零，才播放专属对白和普通撤退动画，交代亲随带他由北门逃往傥骆道。未制作逐格逃跑动画，也不补血复活或设置无敌。

先击退贾充仍须交涉并接回旧卒；最后击退贾充，先演撤离再结算。若同次我方关键人物或待救旧卒被击溃，失败优先。撤离旗标只置一次，避免重复对白。原作S46有贾充兵力归零触发专属对白的写法；本关采用0x53末参0普通撤退，保留后续生还剧情。

## 部队与流程

- 原图m005，24×24格，不改图片和地形。5名玩家武将、5队友军（含3队旧卒）、31队敌军，共41个实际单位，敌我比3.1:1。
- 玩家为姜维、王含、关彝、诸葛果、宁随，20级基准。袁綝及北门蜀兵在北侧牵制。
- 敌军为主城贾充1队、西门督战队10队、城内主阵12队、北门守队8队。保留上次扩军的全部30队兵种兵。
- 王含与中间一队旧卒邻接后交涉；先击退两队督战弓兵时使用专门对白。三队旧卒原地待命，交涉后撤往西南接应区(8,16)至(12,19)，同一实体的血量、装备与状态保持。
- 交涉后西门与北门前队出动；交涉后的第3回合起城内主阵出动，第6回合起北门后队出动。迟交涉会补触发已到期事件。贾充保持主城坚守。
- 胜利须交涉完成、三队旧卒全部接回、贾充撤离剧情完成、所有敌军清零。任一玩家武将、袁綝或未接回旧卒被击溃即失败。
- 20个可操作回合，第21回合超时优先判负。沿用0x59结算，不额外设置贾充掉宝。

战前R取自第七回“马后头”，经编成出兵进入S；战后R接既有战果、“骆谷”与“第一个”。这些是独立样关R00/S00/R01，不是整部长篇的正式重编号。对白正本为[对白.txt](对白.txt)，可读全文及验证报告在[样关包](样关包/阅读说明.txt)。

## 部署与读档

本轮仅替换游戏 `E:\ccz-new-engine\1-工程源码\bin\Release\RS\S_00.EEX`；旧版同目录留有“贾充修复前”后缀的.bak。游戏R00/R01仍是此前恢复的正式剧情入口，Data及其他RS没有变化，点“重新开始”不会直接进入独立样关。

仓库根运行 `python -X utf8 project/battle_build/verify_lecheng.py`，默认输出到被忽略的 `project/mod_build/build/lecheng`；构建器本身不部署。正式样关快照保存在 `样关包/`。

本轮样关R00/R01与样关Data也逐字节保持；构建Data仍只使用此前四个新增士兵槽874～877。正式十七回源稿、R镜像和游戏其余文件均已核验保持。

以上为静态与事件模型验证，不是实机测试。未启动游戏；AI平衡、动画镜头、原生战中存读档与20回合通关余量仍待实际游玩。
