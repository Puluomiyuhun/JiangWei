# 第十三回《旧营》试读

两段人物相处。完整回目另含出关与魏吴变化；此处不提前揭露长线结局。

```
[事件名] 树下
[音乐] 107
[场所] 汉中 郊外
【杨兰】那边。就那棵树，不去营门，也不顺路看粮车。
【姜维】我还没说什么。
【杨兰】你刚才往那边看了三次。
【姜维】……好，去树下。
[移动] 姜维 46 53 1
【杨兰】坐。衣服弄脏了自己拍，别摆出一副等人请你上席的样子。
【姜维】地上有蚂蚁。
【杨兰】我也看见了。大将军，要不要给你搬张榻来？
【姜维】不用，不用。
【杨兰】（真坐了。这人也怪，叫他往刀子前面站，眼都不眨；叫他好好歇一会儿，倒像亏欠了谁。）
【姜维】你拿叶子做什么？
【杨兰】吹个曲儿。小时候会，方才试了试，忘得差不多了。
【姜维】我可以教你。
【杨兰】你先吹。
【姜维】……
【杨兰】噗。你这叫吹曲儿？
【姜维】叶子太老了。
【杨兰】行，怪叶子。我给你换一片嫩的。
【姜维】不用找了。我也不大会。
【杨兰】我知道。刚才就知道。
【姜维】（以前她这样笑，我总急着找一句话回去。今日竟只想叫她多笑一会儿。她在永安听过多少天喊杀，回来却还得先问我累不累。）
【姜维】兰，你若不想再去前锋……
【杨兰】今天不说这个。
【姜维】我不是要拦你。
【杨兰】我知道。可你一心疼我，就开始给我换差事。先陪我坐着，好不好？
【姜维】……好。
【杨兰】把手给我。
[移动] 杨兰 50 53 3
【姜维】这里有人过。
【杨兰】那又怎样。认识你的人，还会不知道我是谁？
【姜维】也是。
【杨兰】（这回倒答得快。可别过一会儿，又在我手心里比画山川形势。）
【姜维】这趟走完，若能早回来……
【杨兰】伯约，别许明年的。今天还有半个时辰呢。
【姜维】嗯。
【杨兰】再试试那片叶子吧。我不笑你了。
【姜维】你方才也是这么说的。
【杨兰】那是方才。快吹。
```

```
[事件名] 旧营
[音乐] 57
[场所] 五丈原 旧营址
【杨兰】先生，你在找什么？这里的木头早烂了，就算从前藏过酒，也别挖出来喝。
【宁随】不是找东西。看看土。
【杨兰】……这土有什么好看？
【诸葛果】兰姐姐，果想同先生待一会儿。
【杨兰】好。我去坡下等，不走远。
[退场] 杨兰
[移动] 宁随 55 41 2
【宁随】这里大约是旧沟。年年下雨，填了，又被冲开，已经看不出原样。
【诸葛果】先生从刚才起，一直绕着中间那块平地走。
【宁随】有些地方，走惯了便不愿踩过去。
【诸葛果】父亲的帐在那里？
【宁随】……嗯。
【诸葛果】（当年果忙着帮师兄解围，满心都是怎样退兵，竟没有好好看过这片营地。如今终于能停一停，最想见的人，却早已不在了。）
[移动] 诸葛果 55 51 0
【诸葛果】幼常叔叔。
【宁随】……许久没听你这样叫了。
【诸葛果】平日在军中，大家都叫先生。叫得久了，果自己也只来同您说军务。
【宁随】此处又没有旁人，想问便问吧。
【诸葛果】父亲从前认识的人，越来越少了。果怕总说来日有空，最后连您也问不着。
【宁随】（她回来以后，从未催我说这些。我便只当她能自己排遣，还觉得省心。一个孩子若总不来麻烦人，我们竟真能一直装作看不见。）
【宁随】我在。你想知道什么，今日慢慢说。
【诸葛果】若有些事您也不知道，就告诉果不知道。不要又替父亲劝果，要以大事为重。
【宁随】好。
【诸葛果】他最后在这里，常提到家里么？
【宁随】提。瞻儿的信来时，他叫人念过，又嫌念得慢，自己拿去看。
【诸葛果】小瞻那时还写不好字。
【宁随】丞相看得懂。看完又说，这孩子太早懂事，未必是福。那时候我听着，没十分明白。
【诸葛果】……后来人人都叫他诸葛武侯的儿子。他想做什么，都要先想这一句。
【诸葛果】（果以前也说过，瞻儿该懂事了，瞻儿不要让父亲失望。原来父亲自己，还想让他慢些。如今果知道了，又能告诉谁？）
【宁随】瞻儿在绵竹的事，我……
【诸葛果】今天不要劝果。果同兰姐姐聊过他小时候，笑得出来，可想到绵竹，还是会恨。
【宁随】那就恨一会儿。不必因你师兄正在用魏军，连你私下难受也要一并收起来。
【诸葛果】果若当着他这样说，他会更难受。
【宁随】他难受，不等于你说错。只是我也没有好到哪里去，平日怕他分心，总叫你们先忍一忍。
[音乐] 39
[登场] 姜维
【姜维】果儿，兰说你在这里。
【诸葛果】师兄，果想在原上留一小会儿。天黑以前回营，不会独自走远。
【姜维】我陪你。
【诸葛果】……好。先别讲明日如何进军。
【姜维】不讲。
【宁随】我回去看看。
[退场] 宁随
[移动] 诸葛果 55 51 3
【诸葛果】师兄当年离开这里的时候，是不是以为，很快便会再回来？
【姜维】是。后来每次出兵，也总觉得下一回便能做成。
【诸葛果】果从前听着，也信。父亲走了，师兄还在，总觉得还有人能把那些事一件件补回来。
【姜维】（我最怕她不再这样看我，又怕她一直这样看我。丞相没有做完的事，我接了；她失去的家人，我却一个也带不回来。）
【姜维】果儿，有些事，我补不了。
【诸葛果】果知道。不是今日才知道。
【姜维】……嗯。
【诸葛果】坐吧。站着说这些，像来祭告一样。果只是想看看，父亲最后看过的地方是什么样子。
[移动] 姜维 50 51 1
【姜维】那年风也很大。丞相的帐幔，总得多压一块石头。
【诸葛果】在家里也是。母亲说过他好多回，别把什么石头都往屋里搬。
【姜维】这件事，我倒不知道。
【诸葛果】果知道一些。今日换果说给师兄听。
```
