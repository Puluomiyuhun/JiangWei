# 十三回可读性修订说明与试读

本轮改49场、80处，正文净增599字符，仍为十三回209场。重点处理第九至十三回，同时回查前文的承诺、兵数和关系。第一回完整保留。本文件含截至第十三回的剧情信息，不含远期结局。

主要改法：让读者在人物作决定以前，知道争的是什么、双方各得什么、答应到哪里。该留的复杂关系仍在，已经解释过的地方则少说一次。没有把温情场面改成政治说明。

## 先看几处短对照

### 第9回《三千人的来处》

修正与当场八千请求不一致的五千，点清交换条件，并保留姜维对故人的私情。

原句：

> 【姜维】（他不肯给五千，倒把给罗宪的书先写好了。这封书若不带，兵也难要。……令则肯收么？总得先送到他手里。）

改后：

> 【姜维】（八千援兵，他只肯给三千，倒先写好了招揽罗宪的信。我要救令则，就得替他递这封书……令则怕是又要骂我了。先送到他手里吧，收不收由他。）

### 第11回《谁的诏书》

明确已经证实和仍未查清的分别，不再用两半指代。

原句：

> 【钟会】那就接着找。不能因为樊建认了一半，另一半便全当真的。

改后：

> 【钟会】接着找。樊建认的是送过兵数，不是认了这张抄件。谁添了截粮的话，谁又送给伯约，仍须查。

### 第12回《没有遗诏以后》

将多留一处可说展开为两次相反操作及各自目的。

原句：

> 【夏侯和】公主没有给我诏。我当日在成都说太后临终没见任何人，是想逼你与诸将决裂；后来又提她见过公主，想给这份军约多留一处可说。都是我自己的意思。

改后：

> 【夏侯和】我也认一件。成都那夜，我先说太后临终未见人，想叫诸将不肯签，让你同他们决裂。后来又说她见过公主，是故意让人以为遗诏可能有来历，好继续议约。公主从未给我诏，两次都是我借她的名。

### 第13回《谁来做皇帝》

改掉新主将与私分恩典的双重比喻，让丁奉要求落实。

原句：

> 【丁奉】我在宫门等。接来的若是一位天子，不是一家人的新主将，今日便不要先私分他的恩典。

改后：

> 【丁奉】我在宫门等。两位要迎他作天子，就别先替他许官、分兵。宫卫也仍照今日说定的，由我守着。

### 第7回《汉中是谁的》

```
[事件名] 汉中是谁的
[音乐] 50
[场所] 乐城
【钟会】乐城旧部归王含，照前约办。句安，你去接管南郑，城里的钱粮人事和城外粮仓，先交给你。
【钟会】（兵已还给王含，若郡吏、仓粮也全交还蜀国旧人，我在汉中便只剩一支等他们给饭的军。句安未必能干，可他熟悉魏军接收的册籍，我还能借他核住这些粮。）
【王含】末将不是来讨太守。四千弟兄愿跟回来，是想家人能留在汉中，拿回田地过日子。如今兵归我带，家属领不领得到粮、拿不拿得回田，却要等句安查册？
【句安】该给谁家粮、哪块田归谁，总得查清。去年魏军接管以后，也分过田、安置过人。不能只凭一句旧部归来了，就把现在住着的人赶走。
【蒋斌】司徒，我赞成核旧册，不赞成迁军属。汉城旧吏中有肯回来办事的，他们认得县里的人，也认得句将军。若全换成我们带来的武人，政令下不去。
【王含】蒋将军，你的汉城没有今天流的血，也要我这四千人替地方的安稳让路？
【蒋斌】汉城奉诏开门以后，一样有人被分走。我求的是旧吏复任，不是叫你交兵。这两件不能并成一件吵。
【蒋斌】（我家的旧望还在，汉城却是我亲手降的。如今若连肯回来办事的旧吏也保不住，以后谁还认我？王含以为我只顾句安，真是冤枉。）
【姜维】兵仍归王含。家属先留在原处，田地归谁，交城里的官吏查清，不能直接征走。句安管南郑，仓里有多少粮，军中另派人同他一起点。
【钟会】可以。句安熟悉魏军接收后的旧册，正可使前后衔接。汉中不只住着蜀兵，也有魏军留下的吏卒和家属。
【王含】那弟兄们的家属，眼下靠什么过活？
【钟会】先照军中名册给粮，不必等核田。能不能免役、原来的田还得回多少，查清以后再议。
【王含】大将军，末将今日才明白，归还旧部，不等于他们能回原来的家。
【姜维】这一项，我没有替你争到。你仍守乐城，不必随我北行；家属有迁徙令，先报你，不准绕过。
【王含】我守。可是再来调人，不能只说一句大将军有难。
【姜维】我记下。
【钟会】句安，散在外线的魏兵若愿归，你可以谈；军仓不可私给，得把数目和条件报来。别只报大家都肯听的话。
【句安】末将遵命。
```

### 第11回《兄弟的两种差事》

```
[事件名] 兄弟的两种差事
[音乐] 4
[场所] 建业 薛府 官署
【薛莹】兄长，这是华覈按陛下旨意拟的诏文。免征的边界都写在里面了。
【薛珝】放着。你先看看我这边收到的，陶璜要见的人，半数连我都没听说过。
【薛莹】你是怕他借此收自己的旧人？
【薛珝】收得住还好。我怕他借了朝廷的名，人没收来，答应的东西先得我去要。
【薛珝】（文书房里的弟弟，见一封诏能改下来便高兴。我在外头，得替诏上每个字找得到人做。偏偏他总觉得我不愿听道理。）
【薛莹】你不是也去过蜀国，认得那边的人？当时回来说蜀廷只会说好话，如今轮到自己办事，才知道回书也有难处。
【薛珝】这两件别混。成都那些人一见我便争着送东西，百姓过得怎样，半句不肯说。你修书时倒要给他们留个体面？
【薛莹】我没有要替他们隐瞒。可南来这封信，若只写吕兴谋逆，不写孙諝怎样役使百姓，以后看的人还是只知道派兵。
【薛珝】（弟弟跟着韦昭、华覈修书，觉得孙諝苛役致乱就该明写，我也知道没说错。可张布正在盯我怎么用人，这时再翻他保荐旧吏的账，我去要钱要兵，只会更难。薛莹敢得罪的人，我还得去同他们办事啊。）
【薛珝】孙諝怎样逼反百姓，该写就写。但不能拿我的几句私话，替陆凯指控谁荐错了人。要我作证，就让我看清楚，亲自署名。
[登场] 陶璜
【陶璜】薛将军。爨谷遣到江上的族人回了话，说可替我们通交趾，但先要南中往来的商旅不受留难。
【薛珝】他不是在替霍弋出力？
【陶璜】他在替爨家找好处，未必听霍弋的。哪边肯让他的商旅通行、肯给官，他便往哪边谈。我们先别把他当作霍弋的使者。
【薛莹】那我们给了他好处，岂不是也养着霍弋？
【陶璜】有可能。所以先许商旅通行，验明货物、人名，不许他带兵过界。见到交趾那边真肯回话的人，再议下一步。
【陶璜】（这位是薛将军的弟弟。兄弟两个，问的倒不一样。一个怕我办不成，一个怕办成了，却成了别人的好处。）
【薛珝】依这个回。别替他求太守，朝廷还没拿回交趾，哪有任他挑的官。
【陶璜】还有，留平营里有几个走过南路的军吏，臣想借用两人。先前派去问，都说须请都督。
【薛珝】问陆抗？你把名字给我，我照陛下新命去借。
【陶璜】要先问本人肯不肯。有些人与北来商旅通婚，叫他到南边招抚，可能先把自家买卖吓散了。
【薛珝】你问。陆抗那里我写书，不叫你拿着空口去讨人。
【薛莹】兄长，这封能不能留一份给我？
【薛珝】这封可以。别又拿错旁边那一封。
【薛莹】（上回我没拿错，是他后悔给了。……罢了，今天肯给这一份，已经很好。）
```

### 第12回《借走的人》

```
[事件名] 借走的人
[音乐] 70
[场所] 西陵 议事厅
【虞汜】薛珝将军要遣人联络交趾旧吏，请西陵借两名熟悉水路的军吏。名单上的两人都说愿去，还请都督放行。
【留平】名单里有步协的旧人，前次押粮，我借来掌过船，如今已经还营了。替我办过几日差，便算我有权把他调走？
【陆抗】先别用那个人。另问，不许为了凑两个，把已经答应归旧营的再抽出来。
【留平】都督，我肯借人。可不能他们先同军吏谈妥，再来营里领人。人调走了，谁来顶他的差事，总得容我安排。
【留平】（我先前要各营自报，是怕本营的功劳被一句都督督军有功盖过去，不是想同陆抗拆伙。如今薛珝来借人，陆抗仍肯替我拦先领走再议，我这边也该挑两个能办事的，不能只说不给。）
【虞汜】所请之人可以再议。朝廷没说见了名便可强取，薛将军也怕带去的人不肯做事。
【陆抗】留平，另取两人，由你荐，仍记原营之功。荐去的陆家那个孩子，不在其中？
【留平】不在。他还没走熟西陵，去了只会给人牵马。
【陆抗】那就留下。别因为是我荐的，连他会不会做都不敢直说。
【陆抗】（我原先还怕留平碍着陆家的面子，不会用也得留着。如今他肯直说这孩子还没本事走南路，倒是认真在教他做事。我也别急着替他再求一份好差。）
【虞汜】还有董厥的书。成都想借商旅，买粮过江。称不运兵械，仍请依两国旧交。
【留平】永安才退兵，他便要从我们这里买粮？
【陆抗】姜维有粮，能在北边牵制魏军，对我们有利。粮还是他出钱买，为什么不谈？
【陆抗】只是他少向南中征粮，霍弋便可能腾出人粮去帮吕兴。不能北边牵住了魏军，南边又让魏国多得一块地。
【虞汜】薛将军也是这个意思。陶璜请将准通商的范围写明：不携军械越界，亦不借商道运兵援吕兴。
【虞汜】（陆抗也怕霍弋援吕兴，这就能谈了。薛珝要收回交趾，眼下借陆抗管的这段粮路，比只催他出兵有用。）
【陆抗】管得住沿江这一段，管得住霍弋走陆路么？
【虞汜】薛将军也怕这一点。霍弋若帮魏国守稳交趾，我们便南北都要防魏，西陵也抽不出兵来。请都督一起署书：肯通粮，但南中继续援吕兴，吴国便停这条粮路。
【陆抗】（薛珝想用通粮换南中不援吕兴，却要我署名保证放船。若建业日后又来扣粮，成都只会说陆抗失信。能保的只保眼前这批，不能替新条件许一条永不变的江道。）
【陆抗】首批船验过，西陵便放行。以后的粮能不能运，要等南中答复，也须陛下准许。董厥自己答应，未必能管住霍弋。
【留平】那首批先放，后面的等回话。我叫江边照这个办。
【陆抗】先把回书送去。吴境这段我能管，到了永安，还得罗宪准上岸；不能叫成都误以为，我连整条粮路都替他们保下了。
【虞汜】都督肯署首批通行，陶璜便能拿它去问南中各家。他们未必肯为吕兴，舍掉成都这边的买卖。
【陆抗】（南中诸家若舍不得这笔买卖，便会去拦霍弋援吕兴。不必人人替吴国说话，肯有几家反对，霍弋就难出兵。陶璜倒找对了人。）
【陆抗】给薛珝一份，也给留平一份。船到以后须照这份放，别叫步协以为，我们又在私下替罗宪送人情。
【留平】我去同他说。这次让他也看全书，不只是领一句退后阵的令。
```
